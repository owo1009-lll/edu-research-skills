# Reproducing the English L-C01 comparison

Use a new external experiment directory. Keep it separate from the repository, installed skills and previous runs. Public inputs are in inputs/D-L02. No private materials are needed. This protocol reproduces the procedure and frozen resources; unavailable hosted sampling settings prevent deterministic text regeneration.

1. Check out source commit `331eccc73459770dedad8c1f5f747929f69312f5`. Use `../writing-20261018/snapshot.py --source <checkout> --out <root>/variants/v1 --manifest <archive>/snapshots/control.json --label lc01-control`. The control manifest records 203 files and tree SHA-256 `2ac357f06b434ea2d36bf021e70ea3371dea47c5cfb90ed053164c440f04c147`.
2. Use `../writing-20261020-qc01/prepare_variants.py` with that control and manifest, a new `<root>/variants/v2`, and a candidate manifest path. Pass `--target skills/edu-writing/references/qualitative-narrative.md --addition candidate-addition.md --label lc01-example-only`. Only the specified file changes. Expected candidate tree SHA-256: `3c3c18f8d58da949f5ed6036ca3c1998c3b7bc95a11045dafb7c8c1dacb6a2c5`.
3. Copy inputs/D-L02 byte-for-byte to `<root>/inputs/D-L02` and check input-freeze.json. The actual original paragraph was extracted from the publicly available, CC Attribution publisher-layout PDF and line-wrap-normalized before freezing. It contains 159 whitespace-delimited words. The source pack identifies its edition and precise page, distinguishes observation from accounts and marks unread cited sources. No full article is redistributed.
4. Instantiate writer-wrapper.md for `new` and `revise`, repeats 1 and 2, versions v1 and v2. Each run uses a fresh agent with no inherited conversation and outputs to `<root>/runs/D-L02-<operation>-r<repeat>-<version>`. Retain all actual stages and failed attempts. Give neither arm the developer design, candidate rationale or expected answer. The candidate example is encountered through its normal qualitative route.
5. After all four manuscripts for an operation finish, run `../writing-20261020-qc01/prepare_review.py --root <root> --case D-L02 --operation <new|revise>`. Copy review-brief.md into the resulting blind operation folder. Give a fresh reviewer only that folder and its own output folder. Keep keys separate. Save actual review.md, review.json and input-hashes.json; do not rewrite after unblinding.
6. Prepare a new archive directory containing the exact inputs, freeze and snapshot manifests and run-config.json. Use `../writing-20261020-qc01/archive_results.py --root <root> --out <archive> --case D-L02 --new-words 350 450 --revise-words 90 110`. It rejects an existing archive, checks resource/input digests, manuscript language/length and correspondence of the anonymous copies. Only the local root prefix is aliased in published artifacts; both original and published hashes are preserved.
7. Separately review writing quality against the source and original paragraph. Input integrity, script exits and word counts do not establish explanatory value, authorial fidelity or quality improvement. Record ties, local problems and reviewer disagreements as well as useful changes. All reviewers in this batch use the same model family; no human-review or final-holdout inference follows.

The helper scripts remain those published with the preceding Q-C01/M-C01 development work. Keeping executed versions of each writer's own helper is part of record preservation, common to both arms. Resource manifests remain writer reports verified against file bytes, not independently instrumented traces of every read.
