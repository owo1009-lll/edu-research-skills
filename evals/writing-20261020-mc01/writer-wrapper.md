# Writer wrapper used for all eight runs

The following prompt was instantiated with each run's version, operation, repeat and output directory. For `revise`, the input list additionally included `original.md`; for `new`, it did not. Each writer started with no inherited conversation. The hosted model and sampling settings were inherited and not independently exposed. The original local path prefix is represented below by `<EXPERIMENT_ROOT>`.

> Complete one isolated English writing task using edu-writing at `<EXPERIMENT_ROOT>\variants\<version>\skills\edu-writing\SKILL.md`. Read the task request at `<EXPERIMENT_ROOT>\inputs\D-M02\<operation>-request.md` and accompanying `source-pack.md` [and `original.md` for revise]. Your output directory is `<EXPERIMENT_ROOT>\runs\D-M02-<operation>-r<repeat>-<version>`. Follow the skill's applicable drafting/checking/self-review/revision workflow. Save the real first draft, subsequent drafts, `self-review.md`, `final.md` and `rationale.md`. Save actual checker output and executed commands; do not recreate missing stages afterward. Record every skill/support resource actually read or executed, with path and SHA-256, in `loaded-resources.json`; record task input hashes separately. Count body words excluding the separate attribution heading. UTF-8 Unicode; prefer apply_patch for prose. Permitted reads: only this request, source-pack [original for revise], specified skill snapshot and your own output. Do not browse, inspect other runs, developer notes, installed skills or the working repository. Do not spawn agents. Produce English prose and English notes. Final response should briefly identify completed output paths without asking for next steps.

The wrapper standardizes preservation of the actual process across arms. It is an evaluation condition, not a new daily requirement for every local edit. The writing request and its word limit are otherwise identical within each operation.
