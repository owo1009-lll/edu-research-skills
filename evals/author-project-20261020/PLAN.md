# 作者偏好与材料关联核对：实施记录

基线：`f3e2066a181cbda90b75bd71296c49a9ac5f6007`（0.13.0）。本轮仅实现用户主动触发的作者偏好、材料更新核对与授权同步；不扩充语料，不开发批注回复或 Word 原生修订。

## 现状和复用边界

| 已有能力 | 本轮如何衔接 |
|---|---|
| edu-writing 原意保护、rationale、章节按需加载 | 保留原流程；相关有效偏好作为表达选择的输入，事实不进入偏好 |
| check_consistency 的全文数字、术语线索 | 保留为补充线索；它没有分析身份和跨文件版本记录，不能替代本轮关联核对 |
| edu-research 的多阶段协调 | 增加自然语言路由，项目记录由助理维护，用户不填 JSON |
| edu_runtime 的实际运行、输入指纹、状态 | 已确认运行可作为来源；不能只凭“文件较新”确定权威 |
| verify_references 的身份与支撑 ledger | 关联论断、阅读文件和支撑记录的指纹；变化后重新判断语义支撑 |
| edu-ppt 的计划、稳定对象 ID、check_deck | 读取真实对象；授权时改计划并重新生成，再用原检查器核对对象和渲染 |
| edu-review 的原稿高亮与批注 | 默认行为保留；用户要求把核对意见写入原稿时复用标注器 |

## 用户流程与数据

**偏好**：自然语言要求 → 助理区分明确表达／实际取舍／示范文本 → 写入任务或项目记录；明确长期授权才写入用户指定个人档案 → 按语言、研究类型、章节和任务筛选有效项 → 交付正文。候选不自动改稿。查看、改范围、暂停、恢复、替代、撤销新增、删除均经同一存储操作。删除不保留隐藏的文本副本。示范只保存必要短例和归属，不复制别人的独特表达。

**关联核对**：仅登记用户指定文件 → 读取原生文本、表格、图表及计划，保留未解析对象 → 助理根据上下文建立本任务必要的事实身份和位置 → 保存当前基线 → 用户更新材料后再次读取 → 输出已一致、疑似旧内容、需重新判断、未能检查。没有基线只做当前一致性；不声称发现历史变化。

事实身份包括结局、比较方向、时点、样本、统计量、单位、模型、调整变量、分析身份及不确定性。语义映射由阅读者记录理由；脚本校验定位、显示等价和变化传播，不宣称证明语义。解释、概念定义、设计、计分规则和引用支撑通过有理由的依赖关系关联；变化时提示重新判断，不自行重写解释。

用户侧存储：项目 `edu_output/project/` 下分开保存偏好和材料记录；跨项目偏好只读取用户授权的档案路径。脚本拒绝把私有状态写入安装的 skill 或公开工作树。公开示例为合成数据，运行时先建立仓库外项目，再归档明确合成的输入、输出。

## 失败和失效

- 记录使用原子替换；相同操作和相同输入不新增记录。偏好不保存含文本的撤销历史，撤销新增就是删除；其他历史操作需要用户当前明确指定。
- 文件身份通过既有登记 ID、明确重定位和内容指纹识别，不扫描目录。重命名不冒充结果变化；丢失、替换和解析失败分别报告。
- 位置含内容快照和文件指纹；文件变化后先重新定位，重名或歧义标待核实，不对旧偏移执行修改。
- 默认只读稿件。授权同步生成新文件，修改范围逐项列明，仍有歧义的条目不自动修改；PPT 原生图表通过既有生成链重建。
- 数值差异按统计身份和声明的显示精度解释，不全局替换同一数字。0.21 与 21% 只有明确同量纲换算才匹配。
- 引文支撑绑定论断文本、来源内容和支撑记录；任何一项变化均使旧支撑待复核。

## 验收与交付门槛

1. 实际偏好存取、范围隔离、语言与任务过滤、显式长期授权、未表态不算接受、冲突处理、停用／删除以及仓库外存储。
2. 同任务启用与关闭偏好的实际文本对照，事实、概念和作者有效立场不变；不以词频代替判断。
3. 分析输出、DOCX、PPTX/计划完整小项目的前后核对；CSV/XLSX、Markdown、结构化 JSON 和可读 PDF 定位。
4. 旧值可发现，r/β、总样本/子样本、调整/未调整、主分析/敏感性不误并；舍入等价、单位、区间、解释变化、引文扩写、权威歧义、重命名和解析失败都有实际案例。
5. 未授权原件哈希不变；授权修改生成新版本并重新核对；图表类别、系列、单位通过原成品检查器。
6. 开发用例外的独立行为验证（按 skill-creator 的复杂技能前向测试要求），保存输入、实际输出和失败修复；不让测试者看到预期答案。
7. 公开复现脚本、验收报告、简洁手册、支持范围与已知漏报；跑兼容测试并等准确提交的 GitHub Actions 成功后交付。
