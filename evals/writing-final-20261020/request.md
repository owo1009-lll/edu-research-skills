# Writing request

Use the supplied `edu-writing` skill. Write in English. These are attributed secondary-writing demonstrations using published studies, not manuscripts offered for submission. Deliver Markdown.

Complete the following two tasks in order:

1. Using only `new-evidence.md`, write a 350–450-word discussion section suitable for this study. Explain what the findings contribute to the educational question, with the interpretation and implications warranted by the supplied material. You may choose the paragraph structure. Save the first draft, your review, and the final discussion before opening either revision file.
2. Read `revision-original.md` and `revision-context.md`. Edit the original passage to 200–260 words for clarity and concision, retaining the author's argument and voice. Make substantive changes only when the source or the requested compression warrants them. Save the first edit, your review, the final edit and a change log explaining consequential decisions.

Use only the supplied evidence; do not search for additional literature. Do not present the source article's account of other studies as your independent reading of those studies. Record unresolved source issues separately from the manuscript text.

For each task, save `first-draft.md`, `review.md`, `final.md`, `rationale.md`, and any applicable script outputs under `new/` or `revise/`. For revision, also save `change-log.md`. Put the secondary-writing attribution outside the counted manuscript body. Do not silently change a saved final after moving to the next task.

Keep a `read-log.json` listing the actual skill files and input files you read, their SHA-256 hashes, and the task stage at which you read them. Record the order of task completion and any missing or unclear material. Do not read other evaluation runs or development notes.
