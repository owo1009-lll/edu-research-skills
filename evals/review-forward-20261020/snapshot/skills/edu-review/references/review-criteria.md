# 审阅维度

意见的依据和改进作用比条数重要。不把缺材料当作已证实的错误，不把个人文风偏好当作期刊要求。具体批注如何锚定见 [文件与锚点](annotations.md)。

## 共同问题

| 维度 | 依据原稿判断什么 |
|---|---|
| 问题与贡献 | 问题值得回答在哪里；相对最接近研究增加、细化或改变了什么认识；不能只以“首次”或地区新颖性代替论证 |
| 概念与理论 | 概念是否清楚且前后一致；理论是否实际参与问题、比较或解释；作者立场是否有可说明的依据 |
| 文献 | 引文是否支持对应命题，是否超出已读取范围；综述是否比较和综合；核实具体文献后才判断缺少关键研究 |
| 设计与证据 | 研究问题、对象、抽样、时点、比较与分析是否相接；数据质量或伦理记录缺失时指出需要核实的材料 |
| 解释与讨论 | 是否回答问题、解释有依据的模式、处理反例和竞争解释；实际增加的认识是否超越结果复述 |
| 实践判断 | 发现、文献或规范前提如何支持行动；区分已检验措施与应用推论，不统一降低建议力度 |
| 表达与结构 | 句间是否推进，抽象概念能否理解，段落是否承担明确任务；删冗余不删主要发现、推理或重要不确定性 |
| 全文一致性 | 摘要、正文、表图、结论的对象、数值、条件、术语和引用是否一致；局部错误修复不转移到其他章节 |
| 期刊与伦理 | 明确的范围、篇幅、声明及程序要求是否满足；只按已核实的目标期刊或实际研究要求判断 |

## 按研究类型

- **定量**：区分实验、准实验、横断面和纵向设计；核对比较对象、主要结局、实际模型与估计目标。结合效应、区间、单位和教育参照理解结果；不显著不自动是无效或等效。方法是否不合适需依据数据结构及实际处理，不能只凭方法名定错。
- **质性**：核对场景、行动、引文、案例差异、过程和反例怎样支持主题与理论判断；区分参与者理解与研究者解释。民族志、案例与主题分析的目的不同，不统一要求频次、统计显著或同一编码一致性指标；缺少统计检验不意味着应弱化有材料依据的判断。
- **混合**：判断为何需要两类资料、各自回答什么、整合发生在哪个阶段与层级。核对联合展示或讨论是否产生单一资料未提供的认识；不强求一致，也不把访谈当作统计机制验证。不同样本不能假装逐人对应，解释型、探索型、汇聚型不要求同一章节次序。
- **理论**：审阅概念、前提、推导、反例与回应；规范判断有其论证依据，不强迫改成实证假设。

批注用红色前须有具体可核查错误；例如稿内同一个样本的两个总数矛盾可指出，但哪一个总数真实仍可标为待核实。认为文献遗漏时写出已读来源及它改变哪项论证；未完成检索不能直接断言没有创新。

## 申报书

检查选题价值与关键问题、学术史和实际增量、内容与设计的相互支撑、研究基础、周期与资源可行性、预期成果，以及匿名与格式。前期事实和预期目标分开；没有依据的“首次”或计划中的结果不能当作已完成贡献。基金指标、活页匿名要求与篇幅以当年公告和用户提供模板为准。

用户要求独立多视角审阅时，可分别聚焦方法与证据、领域与理论、编辑与表达；不设每人问题配额。内部意见出现分歧时，回到原文核查，必要时在同一批注明确未决事项，不把投票当成事实核验。
