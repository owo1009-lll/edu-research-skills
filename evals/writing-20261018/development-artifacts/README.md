# 可检查的开发材料

这里仅包含本项目明确标为合成的 D1/D2 任务产出，没有用户私有稿件、原始参与者数据或专家论文全文。它们是开发对照，不是最终留出材料。

- `runs/`：两项任务、两版本、每版两次生成的首稿、自查、终稿、写作依据、实际读取清单及检查输出。修改任务另有改动记录。
- `dev-p01-skills.zip`：基线运行实际使用的技能文件字节，对应 [基线清单](../snapshots/dev-p01.json)。
- `dev-q01-skills.zip`：候选开发快照字节，对应 [候选清单](../snapshots/dev-q01.json)。两份 ZIP 保留实际换行符，以免不同系统检出方式影响字节核对；不是发布安装包。
- [manifest.json](manifest.json)：产出原始/公开副本校验值及路径别名说明。公开副本把本机绝对路径替换成 `@repo`、`@baseline`、`@baseline_snapshot`、`@candidate`；JSON 重新排版，正文不作编辑。匿名稿仍保留原始 final.md 字节。

检查时先看 [任务材料](../inputs/) 与各次终稿，再看 [匿名稿](../blind/) 和 [评阅](../judges/)。版本键只在评阅结束后公开，不提供给评阅上下文。

要重新运行，将两个技能 ZIP 解压到不同的新目录，核对清单 SHA-256，分别给独立写作上下文相同的请求与材料，使用 [任务包装](../writer-request-template.md)。检查器位于各自快照的 `skills/edu-writing/scripts/`。这可以复查输入和工作流，不保证不同模型或不同采样得到逐字相同的输出。
