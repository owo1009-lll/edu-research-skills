# Synthesis writing request

Using the supplied real systematic-review materials, write an English Discussion and a short Conclusion, 500–650 words in total, excluding references. The audience is education researchers and curriculum specialists considering homework policy. Explain what the review contributes and what follows for research or practice. Select and connect the evidence into an argument rather than reproducing the packet as a list.

This is a secondary writing exercise using a published review, not a newly conducted review. Use only the supplied facts and source information. Save first.md, substantive review.md, final.md, rationale.md and loads.json recording actual resources read and their purpose. Run relevant skill checks on first and final drafts, save and inspect the outputs, and keep author queries and checking notes in the work records. Do not browse or inspect other runs.
