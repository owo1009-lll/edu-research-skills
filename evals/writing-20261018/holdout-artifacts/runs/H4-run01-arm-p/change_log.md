# 重要译法选择与修订记录

本表记录英文至中文的翻译选择，以及 first.md 至 final.md 的一轮修订。没有纠正原作者主张或更换论证框架。以下实质修改属于首稿表达、语义或判断力度的修复；不涉及重新分析数据。

| 位置／概念 | 原文／首稿 | 终稿处理 | 具体理由 |
|---|---|---|---|
| epistemic 词族 | epistemic violence / frameworks / exclusions / harms | 认识暴力／认识框架／认识排斥／认识伤害 | 保持社会认识层面的概念关联，避免用不同词把理论框架拆散；只作本次译法，不声称通行译名已核实 |
| facilitator | 原文为引导角色 | 引导者 | 不增添教师身份；全篇统一 |
| community of inquiry | 原文核心组织形式 | 探究共同体 | 保留原有概念与段落承接，不泛化为课堂或学习群体 |
| communicative reciprocity / take up | 原文要求互惠接续与回应 | 交往互惠；按宾语分别译为接续交流、回应、关注并纳入讨论 | 这些行动不表示赞同发言；不使用易引起认同含义的“采纳” |
| 第一段第二句语序 | 首稿“期待……如何……那些体现了其……的陈述” | 先写“面对……发言”，再写对学生的期待 | 减轻嵌套，保持理解范围的主体是学生；原来的 may、at least、may sometimes 不删 |
| 请求回应的主体 | 首稿“要求进一步阐释、澄清，并回应……” | “请参与者进一步阐释、澄清，并对……作出回应” | 原文 asking for 同时支配三项，明确引导者是请求者，不把回应动作全部转给引导者 |
| individual integrity | 首稿“个体的人格完整性” | 保留 | 不缩为诚实或道德操守；未独立阅读 Lardner，不能声称该译法经原著核准 |
| Lardner 引语中的 [a] | 英语中补入冠词的编辑方括号 | 中文不另造冠词括注；三项内容、引号、作者年份页码完整保留 | 汉语译文无对应冠词，去除仅为语法转换；并非删除引语命题 |
| Silver 案例的时间与设想 | 首稿“有时需要”“可以把” | “有时曾需要”“本可以把” | 区分已述的解放斗争观点与对当时引导行为的事后设想，不写成已实施行动 |
| 案例来源 | Silver’s example | “Silver 的案例” | 保留原作者对 Silver 的归属，不把它说成本文作者亲历；不把背景的国家或场景说明加进节选 |
| even if members find fault | 首稿“有所质疑也无妨” | “即使成员认为这些例子存在问题” | 移除“也无妨”的译者口吻，保留寻找反例与不认同反例可以并存的让步 |
| secured a greater good | 首稿“带来更大善” | “实现了更大的善” | 保留伦理判断含义，不限缩为经济效益或社会福利 |
| 二战括号举例 | 首稿“能够……带来新的启发” | “本可启发进一步的讨论” | 保留原文 perhaps 与 would have been 的设想语气；德国、二战末、军事击败三项信息仍在 |
| render the contribution hearable | 首稿“让这项发言‘被听见’” | “让这项发言进入共同体能够理解和回应的范围” | 结合所供背景与段内关系，显明 hearable 的可理解、可回应含义；不改成被认可或说服他人，不声称已经回应 |
| on a literal level, be taken up | 首稿“至少会在字面层面得到回应” | “至少会得到实际回应” | 在本段中与更深的概念工作相对，指最基本的交流接续；避免误读为文字表面的释义。此为语境译法，未查外部解释 |
| neither is possible until | 首稿“在……之前……都不可能” | “只有当……时……才有可能” | 两种句式保持必要条件强度。参与者明确知道会获回应，是两项工作的前提，不是其充分保证 |
| strategies which may reduce | 首稿“策略可以……降低” | “它们可能……降低其发生的可能性” | 恢复措施作用的不确定性；后一个“可能性”是事件发生概率，不是多余叠加限定 |
| have been allowed to permeate | 首稿“得以进入他们的空间” | “被允许进入他们的探究空间” | 恢复准入／排除的反思视角，空间指向本节探究情境；没有断言沉默出于蓄意压制 |
| systems approach | 首稿“研究认识排斥的系统进路” | “关于认识排斥的系统进路” | 避免误读为实证研究方法；保留系统视角及应对不同结构性认识伤害的方向 |

## 保持不改的判断

两处 must 均译为“必须”；群体犹疑仍只是有时可能出现的沉默解释；回应不等于赞同；概念拓展与质疑主导框架仍为二择表达；“并非万无一失的保证”保留在第四段，不按风格清单删除。四段顺序、括号内历史举例、三个原引来源均保留。背景说明没有译入正文。

## 技术修复

首稿与依据记录最初通过 PowerShell 管道写入时中文受损，恢复为 UTF-8 后重新运行首稿检查。该修复不算译文内容修订轮次；故障检查输出单独保留。本次未改动 skill、材料或指定目录之外的任何文件。
