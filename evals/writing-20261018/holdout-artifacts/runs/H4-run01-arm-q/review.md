# H4 译文 AI 自查

这是对所给四段原文及首稿的译文自查，不是外部专家审阅，也未查阅原文全文或被引著作。

## 实质核对

| 位置 | 原文命题与首稿表现 | 自查判断及修订决策 |
|---|---|---|
| 第 1 段，must take up…as a normative value | 首稿保留“必须”和“规范性价值” | 保留；这是作者的规范要求，不因无干预证据而降成“可考虑” |
| 第 1 段，unreasonable—or at least untenable | 首稿译成“可能并不合理——至少难以实现” | “难以实现”容易转成对实践效果或能力的判断；原文在评价这种期待，改成“至少难以成立”。并重组长定语，让学生、发言内容、陌生框架的关系更清晰 |
| 第 1 段，group silence may sometimes result from group hesitancy | 首稿为“有时可能源于群体的迟疑” | 保留“有时”“可能”，并保留“不知道说什么／怕说错”两层；不能把案例沉默的原因判定为迟疑，也不能改写为歧视 |
| 第 1 段，practices they already do…intentionally when these silences arise | 首稿保留已有做法与有意识使用的时间条件 | 保留；没有把阐述、澄清、回应反例写成新发明的干预方案 |
| 第 1 段，Lardner 引文 | 首稿逐项保留个体完整性、共同体责任、无强制与支配 | 保留引文和作者—年份—页码；方括号中的英文冠词 [a] 在汉译中无独立对应，不另造标记。未独立验证 Lardner |
| 第 2 段，if community does not…falls on facilitator | 首稿的条件句先交代陌生框架，再交代群体没有回应 | 主体、触发条件和责任一致，保留 |
| 第 2 段，acknowledged and integrated | 首稿为“得到关注并被纳入讨论” | 保留；不用“接受立场”“认同观点”，以免把回应要求扩大为赞同要求 |
| 第 2 段，Silver、could have、one or both | 首稿保留案例归属，并以“本可以”标记后两项追溯性建议，明确一位或两位女性 | 保留；没有把作者设想的练习写成已经实施的活动，也没有将背景中的案例扩写进正文 |
| 第 2 段，other counterexamples—even if… | 首稿用“说明”连接反例和“更大的善” | 改为“在这些事例中……”，让读者把它读成所求事例的性质，避免中文“说明”被读成引导者要求大家证明该立场；保留成员可认为例子有问题的条件 |
| 第 2 段，WWII 括注 | 首稿保留军事击败德国、或许、本可及括号 | 保留，没有补入具体年份、国家、战役或对暴力的额外评价 |
| 第 3 段，hearable / on a literal level, be taken up | 首稿“被听见”保留了隐喻，但“字面层面”易使中文读者误读为对词句字面意义的分析 | 将后句改为“这些发言确实会被接续和回应”，突出真实发生的交流接续，不把它等同于消除框架层面的排斥。“被听见”在本段保持原文的认识意义隐喻 |
| 第 3 段，neither…until | 首稿表达为“只有……才有可能” | 终稿改写句式但仍保留必要条件：“在参与者清楚知道……之前，这两项工作都无从开展”。不写成回应后概念必然扩展 |
| 第 4 段，not foolproof / may reduce likelihood | 首稿保留非万全保证与风险下降的可能性 | 保留；两处“可能”分别表示策略作用的不确定性与被降低的概率，不能为减少限定词删掉任意一处 |
| 第 4 段，must remain reflective / systems approach | 首稿保留“必须持续反思”，以“提供指引”表述系统取向 | 保留，未扩写为彻底解决一切结构性排斥 |

## 首稿脚本结果与处理

## 一轮修订的范围

实质性调整限于期待的可持守性、反例与判断的句法关系、literal level 的中文表达；另外调整第一段长定语。四段论证、规范强度、案例归属、例证、引文、必要条件和策略作用范围均保留。终稿检查结果将在完成后补录。术语仅据所给材料确定本节一致译法，未宣称为经文献检索确认的通行译名。
