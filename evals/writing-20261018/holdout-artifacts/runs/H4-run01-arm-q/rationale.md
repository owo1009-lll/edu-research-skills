## 动笔前还原的论证

问题是：超出群体主导性认识框架的发言遭遇沉默时，探究共同体如何回应？作者要求将交往互惠确立为规范性价值，并将主动示范互惠的责任交给引导者。群体迟疑只是沉默的一种可能解释；引导者可有意识地使用追问、澄清和反例讨论。实际接续发言，是进一步扩展概念或挑战主导性认识框架的必要条件；这些实践是可能降低伤害风险的保护策略，并非效果保证。Dotson 的系统取向提供应对不同结构性认识伤害的指引，并未被写成解决所有排斥的充分方案。

此处材料是原作者的理论论证与案例解释，不能转成译者的干预结果。Silver 的案例为原作者转述的已发表记述；Lardner 的引文和 Dotson 的引用按原文保留，不宣称独立查阅过这些文献。

## 暂定术语表

| 英文 | 统一译法 | 理由与边界 |
|---|---|---|
| epistemic violence | 认识暴力 | 本节内部与认识框架、认识排斥、认识伤害构成同一概念系列；未核实统一的现成中文译名，不标作学界定译 |
| community of inquiry | 探究共同体 | 保留共同探究及规范性的制度语境 |
| facilitator | 引导者 | 不擅自缩限为教师、主持人或研究者 |
| communicative reciprocity | 交往互惠 | 保留互相接续、回应发言的规范，不等同认同观点 |
| epistemic framework / dominant epistemic frameworks | 认识框架／主导性认识框架 | 不替换成世界观、错误观念或一般个人态度 |
| take up | 接续、回应／纳入讨论（按句法） | 同一行动关系的中文句法变化；不使用暗示赞同的“认同”“采纳观点” |
| contribution | 发言／见解 | 指进入探究的言语内容，不采用生硬的“贡献”作为每次发言的译名 |
| hearable | 被听见 | 保留原文的认识层面隐喻；其与字面上的交流接续的区分须复核 |
| individual integrity | 个体完整性 | 不擅自收窄成诚信、人格尊严或表达自信；所引 Lardner 未独立阅读 |
| gun violence / armed struggle | 枪支暴力／武装斗争 | 两种措辞分别对应，保留作者的概念区分 |
| greater good | 更大的善 | 保留伦理论证用语，不偷换成确定的社会收益 |
| protective strategies | 保护性策略 | 不译成经验证实有效的措施 |
| epistemic exclusions / structural epistemic harms | 认识排斥／结构性认识伤害 | 保留 exclusion、harm 与 violence 的不同词项 |
| systems approach | 系统取向 | 保留理论路径性质，不冒充实施成效 |
