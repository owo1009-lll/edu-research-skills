# 写作依据与工作记录

## 动笔前的主线

本任务为中文质性研究的二次写作练习，新写一个约 500–700 字的“发现与讨论”片段；没有待修改的用户原稿。全部研究依据来自 H3-materials.md 的事实摘记与释义，未读原文，也未读取原作者引用的著作。

教育问题：怎样理解儿童一面认可父母为其生活和求学承担责任，一面又感到亲子疏离的经验。材料回答了“爱”与“亲密”如何并存、亲子互动和学业出路如何进入儿童对关系的理解；没有提供总体频率或成年结局。核心判断：区分责任认可与亲密体验，并通过个案差异理解儿童对关系的主动建构及其条件。贡献以材料支持的概念区分和解释深化为限，不提出新的田野发现。

段落安排：爱与亲密的区分 → 旎旎和阿劲的相处差异 → 阿伟和阿万的关系变化 → 儿童能动性、家庭责任与结构约束。正文保留简短研究范围，最后说明认识的边界，避免每段重复免责。
