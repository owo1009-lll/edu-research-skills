# 路由评测

写作能力的单独验证见 [2026-10-18 全文蒸馏对照](writing-20261018/README.md)，包含任务、冻结快照、原始稿件和匿名评阅。以下表格只记录路由结果，不证明写作质量。

`routes.json` 是 50 条自然语言场景的请求和预期模块（46 条应触发，4 条与教育研究无关、不应触发）。评测方法：让一个只看到各 skill 的 `name` 和 `description`（以及入口 skill 的路由表）的模型，独立判断每条请求该用哪个模块，再与预期比较。

计分规则：预期模块全部出现且顺序一致即通过；`optional_first` 中的模块（入口 edu-research 作为多步任务的协调者）出现在最前面也算通过；预期为空的请求必须不触发任何模块。
