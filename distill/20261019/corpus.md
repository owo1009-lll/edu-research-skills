# 三类语料的获取与精读

本轮仍在进行。每类约 50–100 篇新增论文是首批规模参考；当前队列只是开始，不能用少量易获取文章替代全轮覆盖。数量与获取成功均不证明写作质量。

2026-10-19 用户明确要求从公网寻找。新增来源采用无需登录的出版社全文、大学机构库、作者公开稿和 ERIC 等公开学术文献库；不把搜索摘要当全文，不把用户私稿纳入公开语料。全文缓存保留在仓库外，仓库保存身份、公开来源链接、获取记录、读取定位和原创分析。

## 分组与接触状态

- 旧文复读：保留原 EN/ZH/E/H 标识。旧留出材料一旦用于这轮开发，就不再是独立留出。理论、方法和综述单列为背景来源。
- 新增开发：先记录候选与具体学习问题，再确认全文身份、研究设计和值得学习的实际写法。只读摘要、下载失败、已获取但未分析各自保留状态。
- 独立留出：正式规则确定、实际加载版本冻结后再选新材料。当前队列全是开发候选，不预留其中几篇冒充独立复核。

既有英文基础语料有定量 22、质性 15、混合 13 篇。这是历史清单数量，不是本轮新增数，也不能推定每篇的图表、补充文件和句段分析均已完成。历史部分 W 标记缺失完整身份，去重保留这一限制。

## 覆盖缺口

| 组别 | 要扩大比较的对象 | 选文后须确认的写作价值 |
|---|---|---|
| 定量 | 实验、准实验、横断面、纵向；不同团队与教育任务 | 让理论形成可比较预期；解释效应及模式；围绕具体对象、测量和时间比较文献；不显著或反常结果仍推进问题 |
| 质性 | 民族志、案例、主题分析；不同教育场景和知识传统 | 从互动、行动、话语发展解释；引语前后有分析；比较过程与反例；参与者意义和作者判断均清楚 |
| 混合 | 解释型、探索型、汇聚型；不同整合阶段与层级 | 实际连接样本和推理；一类材料改变另一类材料的含义；联合展示产生可说清的整合认识 |

首批公网队列偏重英语、高等教育、动机与归属，团队也有交叉。这些是后续应补的缺口，不能从此归纳教育写作的普遍范式。中文另建语言分析记录，不能以英文句式替代中文证据。

候选身份和来源见 [第一批](public-sources.json)、[第二批](public-wave2.json)、[第三批](public-wave3.json)。其中 `selection_question` 是筛选问题，不是已经证实的优秀写法；候选类型也须经全文核读确认。获取状态与完成精读记录分开保存，脚本不得自动将“下载成功”升级为“精读完成”。Q-N03 在两批中重试公开来源，仍只计一篇。

当前实际进度见 [reading-coverage.json](reading-coverage.json)：20 个不同 DOI 的新增候选中，公开获取记录有 12 篇取得全文（含背景方法文与待确认类型）；其中 8 篇已完成主文及相关表图的写作分析。中文 X-ZH01 仅筛读首页，另列，不算全文分析。另有两篇旧文复读 Q-R01、M-R01。候选清单和获取记录中的 `not_yet_read` 保留其登记／获取时状态，以实际读取清单记录后续进度。

| 完成分析的组别 | 新增开发文章 | 此阶段能比较的对象 | 尚缺的覆盖 |
|---|---|---|---|
| 定量 | Q-N01、Q-N02 | 情境适配、异质性预期、主要结局与教育意义 | 新增分析仍偏干预且团队交叉；准实验、纵向与不同领域待精读 |
| 质性 | L-N02、L-N04 | 参与时机、角色关系、场合差别、引语与解释 | 两篇局部限用，远不足以覆盖民族志、案例与其他取向；更多强论证范本待补 |
| 混合 | M-N01、M-N04、M-N06 | 解释型案例连接、工具修订逐题取舍、汇聚型功能解释 | 各设计只有局部例子；整合层级、不一致和联合展示仍需更多跨作者证据 |
| 混合分析边界案例 | L-N01 | 同一访谈的编码比例与叙述，持续就读与归属的非对应 | 不视为独立定量／质性两批资料；不替代上述混合设计覆盖 |
| 旧文复读 | 定量 Q-R01；混合 M-R01 | 与新增来源比较具体解释动作 | 不计新增，更不计独立评测 |

每篇笔记包含正面动作与不采纳的推断。整体语料仍显著不足，不能把这 8 篇当作已达到每类约 50–100 篇的规模参考。尚无本轮最终版本独立留出评测；阅读次数不代表验证情境数量。来源失败、版本待核对和去重范围见 [筛选说明](source-screening.md)。

## 可复现获取

复用上一轮的公开获取和定位脚本，不在本轮重复建立下载框架。输出目录须新建且位于仓库之外；示例路径为用户自行选择的 `<cache>`。

```powershell
python distill/20261018/fetch_sources.py --manifest distill/20261019/public-sources.json --ids Q-N01 Q-N02 L-N01 L-N02 M-N01 --out <cache>
python distill/20261018/prepare_reading.py --manifest distill/20261019/public-sources.json --cache <cache> --digest distill/20261019/acquisition-public-wave1.json
```

第二批使用 `public-wave2.json`，本次实际获取 ID 为 `Q-N03 L-N04 L-N05 L-N06 M-N04 M-N05 X-N01`；X-ZH01 为单独首页筛读。第三批使用 `public-wave3.json` 全部 ID。各批必须使用不同的新缓存目录，保留失败与重试记录。相应摘要文件为 `acquisition-public-wave2.json` 与 `acquisition-public-wave3.json`。表图链接来自已取得的出版社主文 HTML，实际请求地址及哈希另存各篇资产 JSON；不依赖开发者本机路径即可寻找同一来源。

获取脚本可拒绝只有摘要的落地页；失败记录保留。PDF 另核对页面及栏序，HTML 的链接表格按分析需要单独读取。读取范围只按实际完成记录，不把补充材料的链接当作已读取内容。
