## 上一轮结果的正确使用

定量比较与解释已有正式改进；混合整合在两次新材料比较中一次局部优势、一次相当，被放在候选目录。这个结果不证明混合方法无价值，也不支持未经检验整包恢复。上一轮最终采用的定量子集没有另外冻结后重跑，因此本轮必须对实际最终加载组合独立复核。

现有普通写作路线遗漏混合研究，而 `analysis-bridge.md` 与 `prose-en.md` 仍将混合结果的交替段落写法规定为要求。另有通用结果模板使用因果措辞、未测因素一律不得成为建议依据、贡献分类标签进入正文等可定位冲突。详见 [直接冲突修复](direct-conflicts.md)。这些修复的正确性依据是前后规则相容及原始论断含义，不冒充风格已改善的证据。

本记录用于开发交付，不改变日常审稿只交付原稿高亮批注版的目标。当前不宣称完成三类语料蒸馏或最终写作版本验证。原稿批注实现及支持范围见 [功能验证](../../evals/review-annotations/README.md)。
