# 27篇中文CSSCI教育学论文怎样写讨论、结论、对策建议与局限

语料：ZH01–ZH27（2025–2026年；量化14篇、质性8篇、混合5篇；9种期刊各3篇，见 `distill/manifest_zh.json`）。
按 `distill/CODING_SCHEME.md` 编码；逐篇记录（含句子编号和摘录）在 `distill/private/zh/coding.jsonl`，仅本地保存。
每篇的摘要和全部讨论、结论、启示/对策建议、局限段落都逐句读过。正文共1,198个有效句，不含表格碎片、参考文献串和小标题。结果部分只在需要时读，主要用来核对不显著结果有没有进入讨论。句子编号 pNN.M 指编码段落的第 NN 段第 M 句，摘要为 p01。

## 定义

- **正文**：编码范围内除摘要和局限单元以外的全部文字，包括“结论与讨论”“研究结论”“对策建议/启示”“结语”。
  - 局限单元：集中陈述不足和展望的那一段或那一节。
  - 局限句若散在讨论中，这些句子本身算作局限单元。
- **发现句**：复述本研究结果的句子（统计结果或质性主题）。
  - 解释（“这意味着……”）和建议不计。
  - 小标题即使写成结论句也不计，另行统计。
  - **直陈**：发现本身不带认识上的限定。
  - **带限定**：发现本身带“可能”“在一定程度上”等。若限定只落在同句附加的解释分句上，仍算直陈（共4句）。中文里没有与英文 suggest 对应的报告动词限定，“研究发现/结果表明/数据显示/访谈显示”都按中性引语处理。
  - **后接免责**：同句或下一句出现免责句。
- **正文免责句（严格）**：正文中限定“数据能说明什么”的句子，如“并不必然意味着……”“不能据此认为……”“不宜视为……”。
  - 用同样的否定词对世界下实质判断的句子不计，例如“A不等于B”“X并非……而是……”。
  - 以“不能/不宜”开头的建议句也不计。
- **设计性提醒（宽松）**：正文中指出某个设计或测量特征可能造成结果的句子，没有“不能证明”式表述。
- **解释实例**：每个独立理由或每次文献比较记一次，不论跨几句。类别如下：
  - 理论：点名或引用的理论/已有观点，以及作者自己的机制推理。两者分开报告。
  - 与已有研究一致：只在明说“一致/印证/契合/吻合”时记。
  - 与已有研究不一致。
  - 研究情境。
  - 并列解释：竞争性解释，以及用“首先/其次/最后”罗列的累加原因。两者分开报告。
  - 每个实例记限定程度：无 / 一个限定手段 / 多个。“可以从……视角加以理解”“可视为”记一个手段。

## 一、各类字段的篇数与比例（27篇）

**讨论开头一段做什么**

| 编码 | 篇数 | % |

- 第一句的功能：

  - 单设“讨论/结果讨论”：9篇。

**3句严格免责句都有同一结构**：只针对一个具体误读，下一步立刻给出东西。

**同样的否定词，更多用来下实质判断。**

- 12篇共27句用“并非/不是……而是……”“并不必然”“不等于”“不能简单理解为……其背后是……”陈述发现的含义。例如 ZH02 由门槛效应推出“高成绩”不等于“高创新”；ZH16、ZH25 也用同类结构提出反直觉结论。
- 这类句子数量是严格免责句的9倍，功能相反：它们收紧的是读者的常识预期，不是作者自己的结论。
- 注意：`results/stance` 的词表指标把“并非、不能、未必、不等于”等都计为 disclaimer，中文论文讨论区中位3.7%。人工编码后，真正限制推断的只占0.25%。改写 skill 时应区分这两种用法，不能一律删除这些词。

|---|---|---|
| 发现上 | 情态或副词（可能、在一定程度上） | 387句中4句，3篇 |
| | 报告动词限定（似乎表明、提示） | 0 |
| | “初步/探索性”这类给整组结果贴的标签 | 0 |
| 解释上 | 候选原因句式：可能的原因在于；可能源于；原因可能与……有关；或源于 | 8篇（ZH02、10、15、16、19、21、26、27） |
| | 带情态的理论框架句：可以从[理论]视角加以理解；可由[理论]解释；可借助……加以解释 | 3篇（ZH15、19、25） |
| | 解释句中的“可能” | 除“与已有研究一致”以外的133个解释中45个带限定（34%）；相比之下，发现带限定的只有1% |
| | 第一人称（笔者认为）、“似乎” | 各1篇（ZH06；ZH01） |
| | 对竞争性解释用“可能……也可能……” | 2篇（ZH16、ZH27） |
| 与已有研究比较 | 几乎不加限定 | 32处一致性陈述中31处无限定 |
| 正文中针对设计 | 严格免责句 | 3句，2篇（见第二节） |
| | 设计性提醒（单题项测量、以参与时长代替教育质量） | 2句，2篇（ZH16、ZH26），都放在对应发现的解释里，作为原因之一 |
| 局限单元 | 测量、设计、样本、推广性 | 11篇；局限句中24%带“可能/或许/或存在”等 |

- 含限定词的句子按位置分：
  - 解释或阐释句：409句中57句（14%）。
  - 发现句：12句出现这类词语。其中4句限定发现本身，4句的限定在附带的解释分句上，另4句是非认识性用法，如名词性的“可能”。
  - 建议句：407句中9句（2%）。
  - 局限句：33句中8句（24%）。
  - 摘要：只有2句，都在背景句里。
- “可能”占全部限定词的约四分之三。“在一定程度上”7次，其余（似乎、或许、可视为、可理解为、加以理解）都只有零星几次。
- 中文论文几乎不叠用限定词：165个解释实例中只有12个用了两个以上的限定手段。
- 摘要的发现句全部直陈。摘要比正文更硬，这一点与英文相反：英文摘要的末句常用 suggest。
- 有两处例外：ZH09 的摘要对认知负荷的表述比正文保守（摘要说没有增加，正文说显著降低）；ZH14 的摘要称各维度都显著，与其结果矛盾。

## 四、结论怎样打包，对策建议怎样组织

**结论**

- 19篇把发现编号列出。
  - 用法包括“第一……第五”“1./2./3.”“（一）（二）（三）”“一是……四是”。
  - 每条的典型顺序：一句结论；补一句统计或质性细节；接机制解释或文献一致性；有时以一句“这意味着/这表明……”收束。
- 4篇用“研究发现：”加冒号，把全部发现压成一段，用分号隔开（ZH04、23、24、25）。
- 2篇按层次或维度并列：ZH01 按微观、中观、宏观三个层面，ZH25 按认知、交互、结果三个层面。
- 11篇让小标题本身就是结论句，如“1.[X]对[Y]具有显著正向影响”“（一）[群体]由[A]转向[B]”。
- 量化论文很少按假设打包：8篇有编号假设，只有 ZH09 按“假设N成立/不成立”逐条写。
- 质性论文常在结论里重新引用访谈原话来佐证（ZH17、ZH18）。

**对策建议**

- 典型结构：
  - 1–2句过渡，说明将从[N]个方面提出建议。
  - 3个编号条目。
  - 每条的小标题是“[四字概括]：[动宾短语]，[目标]”或“以[A]为[起点/核心/导向]，[动宾短语]”。
  - 条目正文先复述对应发现（研究发现/研究表明……），再写“据此/因此，[主体]应……”。
  - 再用“一是/二是”或“一方面/另一方面”细分，常附“例如……”给出一个具体做法。
- 主体加动作：
  - 主体多在展开句出现，如“学校应”“高校可”“教师应”“地方政府可”。
  - 条目首句多省略主体和情态（104句中96句），如“一是构建……”“首先，加强……”。
- 情态强度：
  - “应”是默认的建议动词，97次，20篇的最强情态是它。
  - “应当”只有7次，“必须”几乎不用。
  - 可类（可/可以/可考虑/可尝试）68次，用于具体做法或较软的建议。
  - 需要类62次，多用于“需……”“既要……又要……”。
- 分层设计常见：
  - 按群体类型分别施策（ZH04、ZH11、ZH13）。
  - 按层面（学生/学校/政府，理论/实践/研究）。
  - 按能力水平。

## 五、可复用句式（槽位化改写，不是原句）

**复述发现**

1. 第[一]，[X]对[Y]具有显著的[正向]影响（β=__）；[分组/分位]结果显示，[具体模式]。
2. 研究发现：在[层面1]上，[发现1]；在[层面2]上，[发现2]；在[层面3]上，[发现3]。
3. 访谈显示，[参与者]在[情境]中会[行为]（如受访者[编号]所述）。可见，[范畴]使[现象]，进而[结果]。

**用理论解释**

4. 上述结果可以从[理论]的视角加以理解（[引]）。该理论认为，当[条件]时，[主体]倾向于[行为]；在本研究中，[研究情境]使[主体][行为]，因而[结果]。
5. 这一差异可能源于[两种条件]在[加工层面]的机制不同：[条件A][机制]，而[条件B][机制]。

**与已有研究一致/不一致**

6. 这与[作者]（[年份]）关于[主题]的结论一致，也印证了[作者]提出的[观点]（[引]）。
7. 本研究结果与[作者]（[年份]）关于[观点]的结论不一致，原因可能与本研究[任务/样本/测量]的[特征]有关：[展开]。已有研究也发现，[支持该解释的证据]（[引]）。

**处理不显著或意外结果**

8. 与预期不同的是，[X]经由[M]影响[Y]的路径未达到显著水平。可能的原因在于，[机制解释]；此外，本研究以[测量方式]测量[变量]，未能区分[维度]，这也可能削弱了[效应]。
9. 两组在[维度]上的差异不显著。[维度]更多取决于[其他条件]，[干预]并未改变这一点，这与[作者]的观点相吻合（[引]）。
10. [W]的调节方向与研究假设相反。需要说明的是，这并不表示[常见误读]：[W]对[M]的主效应为正（β=__）；负向调节反映的是[重新解释]。这一现象或源于[机制]。
    （这是正文中唯一推荐的免责句写法：一句，只针对一个误读，紧接证据和新解释。）

**声明贡献**

11. 本研究的主要贡献在于揭示了[现象]在[条件]下呈现[特征]，从而在[维度]上拓展了[理论]对[问题]的解释，并为[实践对象]提供了[依据]。

**对策建议**

12. （[一]）[四字概括]：[动宾短语]，[目标]。研究发现，[复述相关发现]。据此，[主体]应[总措施]：一是[动宾短语]，[具体做法]；二是[动宾短语]，例如[具体做法]。对于[群体A]，应重点[措施]；对于[群体B]，可[措施]。

**局限与展望**

13. 本研究仍存在以下不足：一是[局限1]，后续研究可[对应设计]；二是[局限2]，未来可采用[纵向/实验/多点]设计检验[具体问题]。
14. 本研究采用[设计]，虽然[优势]，但难以排除[具体替代解释]；因此，上述结论应理解为[限定范围]内的发现，未来可通过[设计]进一步检验[因果方向]。

## 六、最能区分已发表论文与免责式写法的五条规律

1. **发现一律直陈**。
   - 387个发现句中383句直陈（99.0%）。有发现复述的26篇中，23篇全部直陈。
   - 只有3篇共4句在发现上加“可能/在一定程度上”。
   - 摘要的44个发现句全部直陈。
   - 用“研究发现/结果表明/数据显示/访谈显示”等中性引语，没有一篇用“似乎表明”“初步提示”之类限定发现。
2. **正文几乎没有免责句，否定词用来下判断**。
   - 25/27篇正文里没有一句“不能说明/不能据此/不宜视为”式的推断免责。全语料只有3句、2篇，占正文句的0.25%。
   - 387个发现中只有1个后面紧跟免责句。
   - 这3句都只针对一个具体误读，并立刻接证据、替代解释或分层建议。
   - 同时，12篇用27句“并非……而是”“并不必然”“不等于”提出实质论断。
3. **限定词放在解释上，不放在发现上**。
   - 解释实例带限定28%，发现1%。
   - 在既有发现又有解释的25篇中，13篇解释的限定比例高于发现，9篇两处都不限定，只有3篇（ZH17、20、26）相反。
   - 常用手段是“可能的原因在于/可能源于/原因可能与……有关”（8篇）和“可以从[理论]视角加以理解”（3篇）。
   - 与已有研究一致的陈述（14篇，32处）几乎从不加限定（31/32）。
4. **局限只写一次、写得短、放在最后，并转成后续研究；不少论文干脆不写**。
   - 16/27篇没有任何局限句。
   - 有局限的11篇中：7篇放结论或结语末段，3篇散在相关发现旁，只有1篇独立成节。
   - 中位3句、约200字、2条；10/11篇把每条局限接到“未来研究可……”。
   - 因果设计问题只在3篇的局限单元里各说一次，从不在每条发现后重复。
5. **不显著和反向结果当作发现来写，不当作局限**。
   - 14篇有这类结果，其中11篇直接报告后给出理论或情境解释，0篇只把它写成局限。
   - 4篇用“与预期不同的是”一类评价性标记把它作为讨论的亮点，3篇用“与已有研究不一致”引出。
   - ZH25 为反常的“高加工—低绩效”结果单设一节，用两种理论解释。

## 七、这些论文在哪里谨慎、在哪里越界

**谨慎之处（可学）**

- ZH19：单设“研究不足与展望”。承认用自然班做准实验可能带来组间偏差，列出已做的基线检验，再把结论的适用范围限定在真实课堂中的准实验。
- ZH10：对反向调节加一句防误读说明，并在结语末尾集中写一次横截面设计的因果限制。
- ZH16、ZH26：把测量缺陷（单题项、以参与时长代替教育质量）当作不显著或弱效应的原因之一，放在对应发现旁边，用“可能”引出。
- ZH27：在理论启示里写明模型的适用条件和边界。
- ZH25：局限三条，每条接一个后续设计，并以一句贡献开头。
- ZH04：明确交代自报数据和间接指标的局限。

**越界之处（不要学）**

- 横截面或相关数据配因果动词：ZH03、06、10、16、26 用“驱动/侵蚀/显著提升了/有效促进”。
- 小样本准实验写成“证实/验证了有效性”：ZH07、14、21，每组十几到三十余人。
- 单案例或小样本质性资料推到全国：ZH01 预测政策后果，ZH05 称策略“可复制”。
- 讨论或建议里出现未经检验的结论：
  - ZH03：对教育公平的影响。
  - ZH05：策略有效。
  - ZH25：教师的组织作用不可被AI替代。
  - ZH26：培训提升了技能。
  - ZH12：从优秀课例的描述性趋势推出因果性的促进作用。
- 不显著读成等效（ZH27），不显著被选择性略去（ZH23，以及 ZH20 的一处），摘要与结果矛盾（ZH14）。
- 强化词：毋庸置疑、无疑、有力地、充分验证等，见 ZH10、12、16、24。
- 10篇的解释一处不限定，16篇没有局限。

改写 skill 时应学这些论文**把谨慎放在哪里**，不学它们的越界。直陈指“不加限定”，不等于“可以用因果动词”。

## 八、与英文SSCI的比较（只列对写中文论文有影响的差异）

依据 `results/coding_summary_en.md`，15篇英文论文。

- **发现**：英文84%直陈，若把 suggest 视为中性则96%；中文99%。英文摘要29%的发现带限定，中文为0。中文没有 suggest 式的报告动词限定可用，所以“研究发现/结果表明”后面直接接结论即可，不需要再找软化词。
- **正文免责**：英文9句、6篇，占正文句1.2%；中文3句、2篇，占0.25%。两种语言都只把它用在单个具体推断上，并立刻接下一步。中文论文的免责更少，skill 生成中文时不应按英文比例补免责句，更不能接近30%。
- **解释**：英文以“与已有研究一致”为主（52%）、44%带限定；中文以理论和机制推理为主（65%）、28%带限定。中文讨论更常见的是“从[理论]来看……”加引注，而不是逐个对照前人发现。
- **局限**：英文15/15有局限单元，12篇独立成节，中位12句；中文11/27有，1篇独立成节，中位3句。中文论文的常规写法是结语末段一段，2–3条，每条带“未来研究可……”。像英文那样写十几句的局限节在中文期刊中少见，但也有（ZH19）。完全不写局限虽然常见，skill 不宜照搬。
- **建议**：英文多为散文段落（11/15），用 should/must；中文多编号（17/27），中位3条，条目首句是不带情态的动宾短语，展开句用“应”，具体做法用“可”。

## 九、编码难点

- **合并章节**：
  - ZH13 的“数据分析与讨论”、ZH18 的“研究结论与讨论”实为结果节，发现句是首次报告。中位数分别给出了含与不含这两篇的结果。
  - ZH14 没有讨论节。
  - ZH05、ZH08、ZH22 的实质性讨论部分落在未标注为讨论的章节里，按指令未编码。其中 ZH22 只编码了“研究启示”。
- **抽取缺失**：
  - ZH20 的“结语”、ZH27 的“总结与展望”标题下没有文字。
  - ZH21 讨论第一小节大部分丢失。
  - ZH10、ZH11、ZH12 的摘要只剩碎片，ZH12 的摘要发现无法恢复。
  - ZH09 的假设3那一句被挤进结果段，已按讨论句计入。
  - 表格和图示文字混入段落的，全部忽略。
- **发现与解释的边界**：一句里既复述结果又附带解释时，按发现本身是否被限定来编码。5句的限定只落在附加的解释分句上，计为直陈。
- **哪些否定句算免责**：
  - “并非……而是”“并不必然”“不等于”大多是实质论断，不计。
  - 以“不能/不宜”开头的建议句也不计。
  - 只有3句限制推断的句子计入。
  - 这与词表指标差别很大，见第二节。
- **限定手段**：“可以从……视角加以理解/可视为/可理解为”按一个限定手段计。“在很大程度上”是强化，不计。
- **解释实例**：
  - 文献比较只在明说“一致/印证/契合/吻合/不一致”时计。方括号引注挂在机制句后，计为“点名或引用的理论/观点”。
  - 用“首先/其次/最后”罗列的累加原因，与“可能……也可能……”的竞争性解释分开计。
- **情态词**：用正则计数，并人工排除“应用、适应、效应、应对、需求、重要、主要”等复合词。“亟待”只在指令性用法中计。
- **立场判断**：判断依据是发现和解释的限定程度、局限的有无与位置、强化词，以及是否有超出数据的论断。没有一篇达到“谨慎”。
