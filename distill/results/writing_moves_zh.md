# 中文CSSCI实证论文各部分怎样写：语步、段落与句子习惯（2026-10-07）

目的：把已发表论文“问题提出/引言、文献综述与研究假设、研究结果、讨论、结论与建议”各部分的写法拆成可执行的规则，供 edu-writing 学习“像期刊论文那样写”。本文件只测写法（语步、段落构造、用文献的方式、句子习惯），不重复已有两份汇总：立场与限定见 `coding_summary_zh.md`，结构与篇幅见 `sections_summary.md`。论文只用编号指代；举例只用不超过12个字的片段或带槽位的模板，不摘录原句。逐篇记录在 `private/writing_moves_coding.jsonl`（本地、不进仓库）。

## 一、方法说明

**语料**：ZH01–ZH27（9 刊各 3 篇，2025–2026；定量 14、质性 8、混合 5）。引用体系：顺序编码制（正文 [n]）12 篇（ZH01–03、ZH07–15），著者—出版年制 15 篇（ZH04–06、ZH16–27）。凡涉及引用密度的指标都分体系报告。

**读了什么**

- 逐段通读：27 篇的引言（共 80 段）；22 篇的文献综述/理论框架节（152 段）；20 篇有实质讨论的论文的讨论或兼作讨论的结论（63 个讨论要点，154 段）；15 篇建议/启示节（84 段，另有 5 篇的建议嵌在讨论或结论中，一并阅读）。
- 抽读：12 篇定量或混合研究的结果段（65 段，人工判读首句）；其余结果部分只做自动测量。
- 每段记录：功能、首句类型、末句类型；每个讨论要点记录：是否先复述发现、是否与点名的已有研究对照（是否带引注）、是否点名理论、是否在要点内给出启示。

**末句类型（人工判读的口径）**

| 代码 | 含义 |
|---|---|
| 泛化收尾 | 末句只做评价或拔高，不含本段特有的变量关系、事实或做法，换到同主题的其他段落后面也成立。典型如“……具有重要意义”“为……提供了……基础/保障”“唯有如此，才能……”“不仅……更……”式价值句 |
| 目的/价值句 | “本研究旨在……，以期为……提供……参考”一类（单列，因为它们几乎只出现在引言最后一段） |
| 具体推断 | 末句给出本段特有的判断、机制或含义（如“这说明A不等于B”） |
| 引证收尾 | 末句是带引注的论断或一条证据，不另作总结 |
| 过渡/引出 | “基于此，提出以下假设”“本文进行如下讨论”一类 |
| 问题/空白 | 末句停在一个空白、矛盾或问题上 |
| 建议、具体做法、做法+目的、展望/局限 | 用于讨论和建议部分 |

**自动测量**（脚本在 scratchpad，未入库）：字数按汉字加全角标点计；句子以“。！？”切分（句末引注 [n] 归前一句）；引用实例 = 一个方括号或一个含年份的圆括号，“作品数”按其中的文献条数计；“作者主导”指点名作者作主语（某某等（年份）发现……/Name等[n]提出……），“泛称主导”指“有研究/已有研究/研究表明……”开头，其余为“论断主导”（论断在前、引注挂在句末）；作者主导的识别经抽样核对，精度高、召回偏低，应视为下限。固定说法按词表计数，每万字。“双‘的’抽象名词链”指一个分句内三个抽象名词由两个“的”串起（如“A的B机制的C路径”这类结构），抽象名词取自 140 个常用词。

**数据质量**

- ZH08、ZH09 双栏串行严重，不计入句长、名词链等句子层指标，段落功能仍按可辨认部分编码。
- ZH07 引言只剩一段（从英文关键词行中恢复）；ZH10、ZH16 引言首段与作者信息混排；ZH20 结语、ZH27 总结与展望为空；ZH21 讨论第一小节部分缺失。
- 跨页处有段落被合并，段数偏少，**字数比段数可靠**。表格、图注碎片和参考文献已剔除。
- 样本只有 27 篇，以教育技术与教师教育为主；所有比例都是方向性的。第二、三节写语料显示的数字，第五节单列我的解释。

## 二、各部分发现

### （一）问题提出/引言（27 篇）

| 指标 | 结果 |
|---|---|
| 长度 | 中位约 890 字（420–2,520，n=26；ZH07 仅 180 字）；按提取段落计中位 2 段（1–7），实际多为 3–4 段 |
| 句长 | 句子中位 55.5 字（各篇中位数的中位，36–84） |
| 引用密度 | 顺序编码制每千字 8.7 处（4.4–19.2）；著者—年制每千字 9.6 处、13.7 条文献；约一半句子带引注（中位 45%–50%） |
| 第一句做什么 | 时代/技术/政策/数据背景 16；对象的重要性或概念界定 9（重要性 6，界定 3）；现实困境 1；理论命题 1 |
| 引用政策或官方文件（纲要、意见、标准、讲话等） | 20/27 |
| 引言中写了现实问题或张力（不是文献空白） | 14/27 |
| 引言中包含文献进展 | 15/27（其余留给文献综述节） |
| 引言中写出研究空白 | 24/27；未写的 3 篇中，ZH02 把空白放在文献综述末尾 |
| 引言中引入理论视角 | 6/27 |
| 最后一段 | 目的+价值 19；研究问题清单 6；泛化收尾 2 |
| 有明确价值句（以期/为……提供……） | 20/27 |
| 研究问题的写法 | 只写目的（本研究探讨/旨在……）14（其中 3 篇把编号问题放在文献综述末尾）；问句 5；编号问题清单 5；单个问句 1；不写 2 |

**语步序列。** 最常见的是：背景（政策/技术/现实数据）→ 对象的重要性或概念 →（已有研究进展）→ 不足（现实困境或文献空白，常以“然而”转入）→ 本研究做什么 → 价值。用 1–7 编码（1 背景，2 重要性/界定，3 已有研究，4 问题/空白，5 本研究，6 价值，7 理论视角），27 篇的序列都能还原为这一骨架的删减或局部重复：16 篇以 1 开头，9 篇以 2 开头；25 篇以 5 或 6 收尾。理论视角（7）只在 6 篇的引言里出现，多数放到文献综述或理论基础节。

**段落开头（80 段）。** 作者自己的主题句或论断 31%；背景句 21%；以“已有研究/学界”作主语 11%；直接写空白（“目前……较为匮乏”“然而，现有研究不足在于”）9%；以“基于此，本研究……”开头 8%；概念界定 8%；“然而”引出现实问题 4%；其余为序数、总括。**没有一段以点名作者（某某（年份）指出）开头。**“然而”在引言中每万字 11.6 次，是讨论部分（1.7）的近 7 倍：引言靠转折制造问题。

**段落收尾（80 段）。** 引证收尾 26%；目的/价值句 25%（几乎全在最后一段）；具体推断 15%；停在问题/空白 13%；泛化收尾 13%（10 段，9 段是开篇背景段，如“……具有重要意义”“……是……的重要基础”）；研究问题 8%。

**空白怎么写。** 跨引言和文献综述末尾统计：
- “多聚焦A，（而）较少/忽视/缺乏B”的对照式：19 篇。这是主导写法，常带具体的A和B，有时用“要么……要么……”。
- 纯缺位（鲜有研究、较为匮乏、尚无研究）：7 篇。
- 方法上的不足（多为思辨、横截面、简单相关）：5 篇。
- 机制或过程不清（作用机制仍有待探究、如何发生缺乏探讨）：5 篇。
- 结论不一致：3 篇，且都写在文献综述内部，不作为引言的主空白。
- 多数论文只写 1–2 条空白；用“一是/首先……最后”列 3–4 条的有 4 篇。空白句带引注的约 9 篇，其余只陈述不引证。
- 空白之后，同段或下一段立即接“基于此/鉴于此/因此，本研究……”（多数论文如此）。

### （二）文献综述与研究假设（22 篇有独立的综述或理论节；另 3 篇把综述写在引言里，2 篇没有）

| 指标 | 结果 |
|---|---|
| 组织方式 | 按主题 9；按假设（每个小节一个变量关系，末尾提出假设）6；理论/分析框架节 6；单段 1 |
| 小节数 | 中位 3（2–4）；小节标题多为“X与Y”“X的中介作用”“X的调节作用”或“……研究现状/相关研究” |
| 点名至少一个理论 | 17/22 |
| 引用密度 | 顺序编码制每千字 7.5 处（1.7–18.7）；著者—年制 9.6 处、10.8 条（1.6–16.7）；带引注句子中位 36%–41% |
| 打包引用（一处引注≥2 条文献） | 顺序编码制几乎没有（中位 0%，最多 16%）；著者—年制中位 10%（0–33%），常为“（甲，2023；乙，2024）” |
| 带引注句子的主语 | 337 句中论断主导 80%，泛称主导（有研究表明……）12%，点名作者主导 8%；作者主导比例高的只有个别论文（最高 47%–60%） |
| 连续三句以上各挂一条文献的“串列” | 占带引注句子的 22%，但其中只有 9/74 句是点名作者式；串列基本是“论断+引注”逐句推进，而不是“某某发现……某某发现……” |
| 末尾补写空白 | 11/22（多为“综上所述，……但……”） |
| 编号假设 | 7–8 篇；6 篇按假设组织的综述，每个假设段都以“基于此/基于上述分析，本研究提出（研究）假设”收尾 |

**段落开头（152 段）。** 作者主题句约 50%；概念界定（X是指/指……/被定义为）17%；序数、转折或总括（第二/其次/然而/综上）16%；以“已有研究/学界”作主语的综合句约 10%；以理论作主语（某理论为……提供了视角）5%；点名作者开头 2%。

**段落收尾（152 段）。** 具体推断或界定 32%；引出假设/过渡 26%；引证收尾 21%；停在局部空白 11%；目的句 7%；研究问题 2%；**泛化收尾只有 3%（4 段）**。

**综合而非罗列。** 常见的综合动作：把研究归为两三类（主要包括两类/从……两个方面展开/共有三派观点）；用“有研究发现……但也有研究表明……”把相反证据放在一起；用“一方面……另一方面”组织机制；每节以“综上”收束并接空白或假设。逐个作者叙述的罗列集中在少数论文（ZH09、ZH20、ZH23）。

### （三）研究结果（简；19 篇定量或混合研究自动测量，12 篇人工判读 65 段首句）

- 段落首句：先用文字陈述结果的 49%；先写目的或程序（为检验……，本研究采用……）的 31%；先指向图表（如表N所示）的 17%，其中近半同一句就接结论；先报数字再解释的仅 3%。
- 统计量 90% 写在括号里（323 个中的 289 个），附在文字结论之后，如“X对Y具有显著正向影响（β=__，p<__）”。
- 结果段中 38% 的句子含数字；含数字的句子中位 4 个数（p75 6，p90 14）。
- 常用引语：结果显示（40 次）、见表/如表（38）、结果表明（17）。“即……越……越……”式的通俗复述跟在统计量后面，16 句。
- 8 篇有编号假设的论文中，5 篇在结果里逐条写“验证了假设HN/假设N成立”（共 18 句）。
- 质性结果的段落（观察，未计数）：主题句 → 受访者原话（带编号）→ 一两句解释，常以“可见/这表明”收束。

### （四）讨论（20 篇，63 个要点）

讨论的位置与组织见 `sections_summary.md`。这里只看要点内部怎么写。

| 指标 | 结果 |
|---|---|
| 要点数 | 中位 3（2–5） |
| 要点先复述本研究发现 | 55/63（87%）；不复述的是随笔式政策反思（ZH01）和以理论家观点开头的质性讨论（ZH24） |
| 与已有研究明确对照（一致/不一致/契合/印证/补充） | 21/63（33%）；其中带具体引注 16（25%） |
| 点名理论或理论家解释 | 23/63（37%）；14/20 篇至少点名一次 |
| 要点内直接给出启示 | 19/63（30%）；多数启示放进单独的建议节 |
| 三步齐全（复述 + 带引注的对照 + 点名理论） | 约 9/63（14%），集中在 ZH06、ZH15、ZH19、ZH25、ZH27 |
| 每个要点的引注数 | 中位 1.25（0–6）；上述五篇为 2.3–6 |
| 小标题 | 13/20 有：断言式（小标题本身就是结论）8；“主题：由A转向B/从A到B”式 3；话题式（……的机制阐释）2。7 篇无小标题，用第一/其次或一是/二是 |
| 讨论中重复具体数字 | 5/20（百分比、分位数、β 等）；其余只用文字 |
| 讨论开头另设一段总述全部发现再说“下文讨论” | 约 6/20 |

**要点的典型顺序**（以 ZH06、ZH15、ZH19、ZH25、ZH27 为代表）：一句复述发现（常以“本研究发现”“针对RQ1”起句）→ 与已有研究对照，一致的直接说，不一致的说“与……存在差异，原因可能与……有关” → 用点名的理论解释机制（“可以从[理论]的视角加以理解”“可由[理论]解释”）→ 必要时补一条访谈原话或分组结果 →“这说明/这意味着”给出含义，有时接一句对实践的提示。更常见的简化版是“复述 → 作者自己的机制推理（附一两条起支撑作用的引注）→ 这意味着”。理论和文献在中文讨论里主要用作解释的依据，逐项对照前人发现的不到一半（与 `coding_summary_zh.md` 中解释方式以理论和机制推理为主 65% 一致）。

**段落收尾（154 段）。** 具体解释、证据、例子或原话 62%；建议 18%；过渡 6%；展望 5%；**泛化收尾 8%（12 段，分布在 9 篇）**。讨论质量较好的几篇基本没有泛化收尾；泛化收尾集中在把讨论写成价值阐发的论文。

**不显著和意外结果**（承接已有编码）：用“与预期不同的是”“另一个值得关注的发现是”引出，给 2–3 个候选原因（首先/其次/最后），其中一个常是测量或设计特征（如单题项、以时长代替质量）。

### （五）结论与建议（承接 `sections_summary.md`）

- **建议小标题**：13 篇有。格式依次是：
  - “[层面/四字概括/群体]：动宾短语”5 篇；
  - “动宾短语，动宾短语”两段式 3 篇；
  - “以A为B/基于A/通过A，动宾短语”3 篇；
  - “主体+应/亟须+动宾”的完整句 1 篇；
  - 短动宾 1 篇。
  - 长度中位约 24 字（6–40）。
- **建议段落的构造**：一句依据（研究发现……/……是……的前提）→“据此/鉴于此，[主体]应……”→ 用一是/二是或“例如”给出具体做法，常按群体或层面分别施策。
- **建议段落收尾（84 段）**：
  - 停在具体做法 20%；
  - 做法加具体目的（“……，以减轻……”）30%；
  - 机理说明 10%；
  - 过渡 12%；
  - **泛化收尾 27%**（23 段），其中 7 段出自同一篇，最常见“不仅……更……”“……是……的重要保障”“唯有如此，才能……”。
  - 15 篇中有 6 篇建议段没有任何泛化收尾。
- **具体程度**：高的论文写出可操作的对象和工具，如设备共享计划、使用声明制度、反思日志、按群体或学科分别训练。低的论文只写“加强……，促进……”，不点主体。

**名词化与“的”**

- “的”每百字 3.0–3.4 个（各篇 1.2–4.7）。
- 一个分句里出现 3 个及以上“的”的句子，各部分中位 0%–4%。
- 双“的”抽象名词链（“A的B机制的C路径”式）在 3,696 句中只匹配到 11 句（0.3%），人工核对约一半是真链。**已发表论文几乎不写这种长串定语**。
- 长名词串主要来自论文自己的核心构念（如某某素养、某某能力），不是修饰堆叠。

**固定说法**（引言、综述、讨论、结论、建议合计 14.1 万字，每万字；“篇数”为出现该说法的论文数）

|---|---|---|---|---|---|
| 值得注意/关注的是 | 0.1 | 0 | 0 | 1.2 | 1 |
| 有待进一步 | 0 | 0 | 0 | 0 | 0（“有待”0.8，7 篇） |
| 具有重要（的）意义 | 0.2 | 0 | 0 | 2.9 | 2 |
| 综上所述 | 0.4 | 0 | — | 3.2 | 6（“综上”1.3，14 篇） |

**自称与英文**

- “本研究/本文/笔者/我们”每千字 1.2–1.4（建议部分 0.5）；“笔者认为/本研究认为”全语料只有 5 次。
- 英文：拉丁字母词每千字，引言 4.1、综述 9.4、结果 15.6、讨论 3.6、建议 0。
- 9/27 篇用英文缩写指称核心构念并高频使用（GenAI、GAI、ConvAI、IVR、SEL、SRL、AI），首次出现一律写成“中文全称（English full name，缩写）”；其余论文全程用中文术语。统计和方法名（SEM、CFI、ENA）只在方法和结果里出现。

## 三、写法规则

每条先写依据（语料数字），再写做法。模板中的方括号是槽位。

### 引言

1. **四个语步，按顺序写，最后一段给目的和价值。** 依据：25/27 篇以“本研究做什么”或价值收尾（目的+价值 19，研究问题清单 6）；24/27 写出空白；中位约 890 字。做法：写 3–4 段、800–1,300 字。
   - 第一段：背景（政策文件或技术、现实数据）加对象的重要性；
   - 第二段：已有研究怎样做、到了哪一步；
   - 第三段：用“然而”转入不足，可以是现实困境，也可以是文献空白；
   - 第四段：本研究的问题、设计与价值。
2. **开头用背景或对象的重要性，不用点名文献。** 依据：16/27 以时代、技术、政策或数据开头，9/27 以对象的重要性或概念开头；80 段中没有一段以“某某（年份）指出”开头；20/27 引用政策或官方文件。
3. **空白写成“多聚焦A，较少B”的对照句，一到两条。** 依据：19 篇用对照式，纯缺位 7 篇；多数只写 1–2 条，只有 4 篇列 3 条以上。做法：A 和 B 都写成具体的变量、对象或方法，紧接“基于此，本研究……”。不要只写“研究较少”。
4. **价值句只写一次，放在引言最后一句。** 依据：目的/价值句占引言段末的 25%，几乎全在最后一段；“以期”全语料 0.7 次/万字，出现在 10 篇里。做法：用“以期为[对象]提供[实证依据/参考]”一句收束，正文其他段落不再重复价值句。
5. **背景段可以用一句评价收尾，其余段落以证据或推断收尾。** 依据：引言泛化收尾 13%，9/10 出现在开篇背景段；其余段落以引证（26%）、具体推断（15%）、问题（13%）收尾。

### 文献综述与研究假设

6. **按变量关系或主题分 2–4 个小节，每节以一个假设、一个局部空白或“综上”收束。** 依据：小节中位 3；按假设组织的 6 篇，每个假设段都以“基于此，本研究提出假设”结尾；按主题组织的论文，11/22 在末尾补写空白。
7. **一句一个论断，引注挂在句末；点名作者叙述只偶尔用。** 依据：带引注句子中论断主导 80%、泛称主导 12%、点名作者 8%；连续单引注句的串列中，点名作者式只占 9/74。做法：写“[论断]（[作者]，[年份]）”。只有当某项研究的设计本身是论证依据时（元分析、关键实验），才写“[作者]等（[年份]）通过[设计]发现[结果]”，每节不超过一两处。
8. **把文献归类、对照，再引出空白或假设。** 依据：综合动作（分为两类、从两个方面、三派观点、有研究……但也有研究……）普遍出现；综述段泛化收尾只有 3%。做法：
   - 小节首句用作者自己的主题句或概念界定（约 50% 与 17%）；
   - 中间给 3–6 处引注支撑的论断，含至少一处相反证据；
   - 末句写理论推演出的方向或假设。
9. **引用密度与引言相当，明显高于讨论。** 依据：综述每千字 7.5–9.6 处、36%–41% 的句子带引注；引言 8.7–9.6 处、45%–50%；讨论 0.6–2.9 处。打包引用在著者—年制中约占一成，顺序编码制几乎不用。
10. **理论放在综述或理论基础节，并点名。** 依据：17/22 的综述点名至少一个理论；引言里引入理论的只有 6/27。

### 研究结果

11. **结果段先用文字给结论，统计量放括号。** 依据：首句为文字结论 49%、目的或程序 31%、图表指引 17%，先报数字的只有 3%；90% 的统计量在括号里；含数字的句子中位 4 个数。模板：[分析]结果显示，[X]对[Y]具有显著[正向]影响（β=__，p<__），即[通俗复述]，假设H[N]得到验证。
12. **有编号假设就逐条下结论。** 依据：8 篇有编号假设，5 篇在结果里逐条写“假设N成立/得到验证”。

### 讨论

13. **每个要点先用一句话复述发现。** 依据：87% 的要点如此；13/20 用小标题，其中 8 篇的小标题就是结论句。小标题写成“[X]对[Y]的影响[方向/程度]”这样的断言，或“[主题]：由[A]转向[B]”；不写话题式的“……分析”。
14. **每个要点至少完成“复述＋解释”，较好的要点再加“对照”和“理论”。** 依据：
    - 点名理论 37%，明确对照已有研究 33%（带引注 25%），三步齐全仅 14%；
    - 集中做到的 5 篇（ZH06、ZH15、ZH19、ZH25、ZH27）每个要点 2.3–6 处引注。
    - 做法：3 个要点里至少 1–2 个写出“这与[作者]（[年份]）的结论一致/不一致”，并配“可以从[理论]的视角加以理解”。
15. **解释用作者自己的机制推理，引注作依据；不确定性放在解释上。** 依据：
    - 中文讨论以理论和机制推理为主（65%）；
    - 发现句 99% 直陈（见 `coding_summary_zh.md`）。
    - 做法：“可能的原因在于”只用于原因，不加在发现上。
16. **启示可以放在要点末尾一句，系统的建议另设一节。** 依据：30% 的要点在内部给出启示；20/25 篇另设建议单元。
17. **讨论段以具体判断收尾，不以拔高句收尾。** 依据：讨论段泛化收尾 8%，具体解释、证据、例子或原话 62%。做法：末句写“这说明[具体含义]”，不要写“……具有重要的理论与实践意义”。

### 结论与建议

18. **3 条建议，每条先挂一个发现，再写主体加“应”，再写具体做法。** 依据：中位 3 条；57% 显式回扣发现（见 `sections_summary.md`）；小标题中位约 24 字，常用“[层面]：[动宾]，[动宾]”。模板：（一）[四字概括]：[动宾短语]，[目的] → 研究发现，[对应发现]。据此，[主体]应[措施]：一是[做法]；二是[做法]，例如[具体做法]。
19. **建议段停在具体做法或其直接目的上。** 依据：做法+目的 30%，具体做法 20%，泛化收尾 27%，其中多数出自少数几篇；15 篇中有 6 篇完全没有泛化收尾。做法：最后一句写“……，以[减轻/提升]+[与发现对应的具体变量]”，不写“不仅……更……”或“唯有如此，才能……”。

### 句子

20. **句长控制在 40–75 字，中位约 55 字。** 依据：主体部分句长中位 54，四分位 38–75；超过 100 字的约 8%（结果部分 13%）。
21. **定语链不超过一个“的”。** 依据：双“的”抽象名词链约占 0.3% 的句子；一个分句里三个以上“的”的句子中位不到 4%；“的”每百字 3–3.4 个。
22. **少用套话，部分说法基本不用。** 依据：
    - “值得注意的是”0.1、“具有重要意义”0.2、“有待进一步”0、“综上所述”0.4 次/万字；
    - “不仅……还/也/更”6.2、“为……提供……参考/依据”3.6 次/万字。
    - 做法：前四种全文合计不超过 1 次；“不仅……更”每千字不超过 1 次；“为……提供……”只用于引言末句和结语。
23. **转折放在引言。** 依据：“然而”引言 11.6、讨论 1.7 次/万字；“基于此”只在引言和综述中出现。
24. **“本研究”适度使用，“笔者认为”很少。** 依据：每千字 1.2–1.4 次；“笔者认为/本研究认为”全语料 5 次。
25. **英文缩写只给核心构念，首次出现写全。** 依据：9/27 篇对核心构念用缩写，首次出现都写成“中文全称（English full name，缩写）”；讨论和建议中拉丁字母词很少（每千字 3.6 和 0）。

### 结构模板

- **引言（3–4 段）**：[政策/技术/数据背景]＋[对象的重要性] → [已有研究主要从A、B两方面展开（引注）] → 然而，[现有研究多聚焦A，较少关注B]／[现实中存在C困境] → 基于此，本研究以[对象/数据]为基础，探讨[问题1、2]，以期为[对象]提供[依据]。
- **综述的一个假设小节**：[概念界定（引注）] → [理论：根据[理论]，……] → [证据：有研究发现……（引注）；但也有研究表明……（引注）] → [推演：由此，X可能通过M影响Y] → 基于此，本研究提出假设H[N]：……。
- **讨论的一个要点**：[一句复述发现] → [与已有研究对照：这与[作者]（[年份]）的结论一致/不同，原因可能与[样本/任务/测量]有关] → [理论解释：可从[理论]视角理解，……] → [这说明/这意味着……]（→ 可选一句实践提示）。
- **建议的一条**：[四字概括：动宾短语] → [研究发现……] → [据此，主体应……] → [一是……；二是……，例如……] → [以[具体目标]收尾]。
- **结果段**：[为检验……，采用……]（可省）→ [结果显示，……（统计量）] → [即……] → [假设HN得到验证]。

## 四、可自动检查的指标与阈值

阈值取自语料分布（大致落在各篇的 p90 或最大值附近），超过阈值视为偏离已发表论文的写法。仅作提示，不作硬性否决。

| 指标 | 已发表论文 | 建议阈值（偏离信号） |
|---|---|---|
| 句长中位（每部分） | 51–56 字 | <35 或 >75 |
| 超过100字的句子占比 | 中位 7%–13% | >20% |
| 引言、综述引注密度 | 每千字 7.5–9.6 处；36%–50% 的句子带引注 | <4 处/千字，或带引注句子 <25% |
| 讨论引注密度 | 每千字 0.6–2.9 处 | 0 处，且没有任何“与……一致/不一致”的对照 |
| 带引注句子中点名作者主导 | 4%–8%（语料合计） | >40%（逐个作者罗列） |
| 段末泛化收尾 | 综述 3%；讨论 8%；引言 13%（且集中在首段）；建议 27% | 综述 >10%；讨论 >15%；建议 >40%；任一部分连续两段都以价值句收尾 |
| 讨论要点先复述发现 | 87% | <70% |
| 讨论要点点名理论或对照文献 | 各约三分之一 | 两者都为 0 |

| “为……提供……参考/依据/借鉴/启示” | 中位 3.2，p90 9.2 次/万字 | >9 次/万字，或出现在引言最后一段和结语以外 |

## 五、解释（非语料直接结论）

- 中文期刊的论证主要在**段内**完成：引言和综述用“论断＋引注”逐句推进，讨论用“复述＋机制推理”。段末多停在证据或具体推断上，泛化总结句只在引言首段和建议部分常见。AI 写作最容易出的问题正好相反：每段末加一句价值拔高，并把“值得注意的是/具有重要意义/不仅……更……”散布全文。规则 5、17、19、22 主要针对这一点。
- 讨论中“对照前人＋点名理论”在语料里不是多数，但集中出现在讨论最扎实的几篇论文中。skill 宜要求至少一部分要点做到，不必每个要点都做，以免写成逐条比对、篇幅膨胀。
- 引言和综述的引用密度接近，说明中文论文的引言本身承担相当一部分文献综述功能。生成引言时不应写成无引注的背景铺陈。
- 建议部分的泛化收尾比例较高（27%），但集中在少数论文；规则 19 有意要求高于平均水平，与 `sections_summary.md` 中“建议要回扣发现”的规则一致。
- 双“的”名词链在语料中几乎不存在，可以作为高精度的自动检查项。“机制”“路径”本身使用频繁（每万字 11–13 次），不宜一律禁用，应检查的是它们是否被叠进长定语。
- 本节所有阈值来自 27 篇论文，教育技术方向占多数。用于其他方向（如课程与教学论、教育史）时需要重新校准。
