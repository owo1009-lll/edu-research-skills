# 证据表

学术史梳理、选题价值和创新点中用到的每条文献依据都登记一行。只登记实际读过、核验过的文献；状态不是"已核验"的，不能写进申报书的论断。

| 编号 | 用在哪一栏 | 支撑的论断 | 文献（作者，年份，题名，刊物） | 核验状态 | 读过的范围与位置 |
|---|---|---|---|---|---|
| E1 | 选题依据 |  |  | 已核验 / 待核实 | 全文 / 摘要；页码或章节 |
| E2 |  |  |  |  |  |

- 核验状态：有 DOI 的英文文献用 edu-writing 的 `verify_references.py` 核验；中文文献在知网等数据库的核实由用户完成或提供条目。
- 只读过摘要的文献，只能支撑关于研究结论的概括，不能支撑关于方法细节的论断。
- 申请人自己的前期成果不列入参考文献（全国教育科学规划活页要求），也不在这里作为文献依据登记。
- 参考文献按 GB/T 7714 著录，数量适中（常见 20–40 条），中外文兼顾，近五年文献占相当比例。
