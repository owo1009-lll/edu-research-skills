# 各栏目写作要点

**选题说明**（全国教育科学规划活页第一栏，300 字以内）：研究的具体问题、研究视角和核心概念。

**课题名称**：研究对象 + 核心问题 + 视角或方法，精炼明确（一般不超过 40 字）；不要写成"……的研究的研究"，不加副标题堆砌，不出现申请人信息。

**选题依据**
- 学术史梳理按问题的推进脉络组织（谁先提出了什么、后来如何深化、现在争论或空白在哪里），不按作者逐条罗列；中外文献都要有，近五年文献要占相当比例。
- 研究动态落到"已有研究做到了哪一步，还没有解决什么"，由此自然引出本课题。
- 价值分学术价值和应用价值，各写具体能推进或解决的问题，不写空泛的"具有重要意义"。

**研究内容**
- 研究对象：界定清楚核心概念、范围和对象群体。
- 框架思路：几个研究板块（子课题）之间的逻辑关系，可配框架图。
- 重点难点：各 2–3 条，与研究内容对应；难点同时写准备如何突破。
- 主要目标：可检验，能对应到预期成果。

**思路方法**（国家社科基金等单列此栏；全国教育科学规划活页没有这一栏，写进研究内容的整体框架和研究计划）
- 每个研究内容对应的方法写清楚：数据来源、样本与抽样、工具、分析方法（如问卷 + SEM + fsQCA、访谈 + 扎根理论、准实验 + 多层模型）。
- 配技术路线图；写明研究计划和进度。
- 可行性：数据获取渠道、合作单位或实验学校、前期预研情况、团队分工（匿名活页中不写具体人名和单位）。

**创新之处**：2–3 条，分别落在学术思想、学术观点或研究方法上，每条都对应选题依据中指出的不足；具体说"本课题在……上首次将……"之前，先确认学术史梳理能支持。

**预期成果**：成果形式（论文、研究报告、咨询报告、专著等）、大致数量和使用去向（如提交教育行政部门、在实验学校推广），数量要与研究周期相称。全国教育科学规划的预期成果结项时必须达到，宁可稳妥，不要多报。

**研究基础**：全国教育科学规划活页只综述前期研究的核心观点（300 字以内），不写成果名称、作者、刊物和时间；其他基金按当年模板。预研、试点或模拟数据写明性质和规模，例如"已完成 2 所学校共 312 名学生的预调查，量表信效度良好"，不夸大为已验证结论。

**参考文献**：按 GB/T 7714 著录，只列真实核验过的文献，数量适中（常见 20–40 条），中外文兼顾。

**语气**：申报书要让评审专家快速看到问题、价值和可行性。句子直接、判断明确；不确定性写成研究要回答的问题，而不是在每段末尾加免责。
