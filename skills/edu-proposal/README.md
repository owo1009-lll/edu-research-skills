# `edu-proposal` 技能

[English](README_EN.md)

撰写和检查中文课题申报书与开题报告，从选题、论证到匿名活页。

## 适合用它做什么

- 全国教育科学规划、国家社科基金、教育部人文社科、省级课题的申报书或活页
- 学位论文或课题的开题报告

## 典型请求

- "按今年全国教育科学规划的活页，写一份申报书"
- "帮我改选题依据和创新之处"

## 你需要提供

- 选题想法、已有材料和前期成果、目标基金和项目类型；当年的公告或模板（有就给）

## 产出

- 活页或申报书正文（Markdown 和 Word）、论证地图、证据表、字数与匿名检查结果、需要用户核实的事项

## 运行和依赖

- Python 3.9 及以上；读 .docx 需要 python-docx

## 边界

- 结构和字数以当年官方公告为准；研究基础只写真实成果；全规的预期成果结项时须达到

## 相关技能

- edu-research（研究设计）、edu-review（评审视角）、edu-writing（引用核验）

## 状态

- Stable：作者已在真实研究材料上使用；全国教育科学规划活页规则按 2026 年模板原文核对；合成选题上试用
