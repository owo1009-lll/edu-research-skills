# 回复格式与语气

## 中文期刊：修改说明

开头一两句致谢（编辑和审稿专家），说明本次修改的总体情况（例如"根据专家意见，我们主要做了三方面修改：……"）。然后按审稿专家分组，逐条写：

| 序号 | 审稿意见 | 修改说明 | 修改位置 |
|---|---|---|---|
| 1-1 | 意见原文（或忠实的概括，较长时） | 做了什么、为什么这样改；引用修改后的关键原文 | 第二部分第（二）节第 2 段 |

- 也可以不用表格，按"意见—回复—修改位置"逐条写；期刊有指定格式时照办。
- 修改说明一般不署名，不出现作者和单位信息（双盲送审时）。
- 每条的致谢最多一句，或只在开头统一致谢；不要每条都长篇感谢。

## 英文期刊：response letter

```
Response to Reviewer 1

Comment 1.1: [reviewer's comment, verbatim]
Response: [what we did and why]
Changes: [section, page and line numbers in the revised manuscript]
Revised text: "[quoted revised passage]"
```

- 开头一段：感谢编辑和审稿人，概述主要修改。
- 每位审稿人单独一节；不同审稿人的意见不互相引用。
- 页码和行号以提交的修改稿（通常带行号）为准；没有行号时写章节和段落。

## Cover letter（重投时）

三到五段：稿件编号和题目；修改的总体说明（最主要的两三处变化）；审稿人意见冲突时的取舍；需要编辑注意的事项（例如某项要求无法完成的原因）；联系方式由用户填写。模板见 `templates/cover-letter-en.md`。

## 语气

已发表论文的写作语气规则同样适用于回复：判断直接陈述，不确定性放在解释上（见 edu-writing 的 [voice-zh](../../edu-writing/references/voice-zh.md)、[voice-en](../../edu-writing/references/voice-en.md)）。

| 不要写 | 改为 |
|---|---|
| 审稿人误解了我们的意思 / The reviewer misunderstood | 我们在原文中的表述不够清楚，已改为…… / We have clarified this in Section 3.2: "…" |
| 显然 / 众所周知 / obviously / clearly | 删去，直接给出依据 |
| 我们完全同意并非常感谢……（每条重复） | 开头统一致谢；每条直接写做了什么 |
| 这一问题将在未来研究中解决（用于能做到的修改） | 已在第……节补充……；确实做不到时说明原因并写进局限 |
| 我们相信这一修改能令审稿人满意 | 删去 |

不同意时的写法：先承认意见指出的问题（如果有），再给出证据和理由，最后说明为避免误读所做的澄清。例如："我们理解专家担心横断面数据无法支持因果推断。本文的假设检验的是变量间的关联，原文第四部分'影响'一词确有因果暗示，已统一改为'预测'和'相关'（第 8 页第 2 段）。"
