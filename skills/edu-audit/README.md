# `edu-audit` 技能

[English](README_EN.md)

核对论文或稿件中的统计结果：用数据或表格复算，或检查统计报告是否完整规范。

## 适合用它做什么

- 复算已发表论文表格中的计数、比例和风险比
- 用原始数据复算均值和标准差
- 投稿前检查结果部分的统计报告

## 典型请求

- "核对这篇论文表 4 的计数和风险比"
- "看看我的结果部分统计报告有没有问题"

## 你需要提供

- 论文或稿件；复算时还需要数据或表格

## 产出

- 原值与复算值对照表、核查报告；统计报告审查表（位置、问题、建议写法）

## 运行和依赖

- 复算需要 R（jsonlite）；报告审查只需要 Python

## 边界

- 复算一致不证明数据真实；回归和 SEM 的复算还没有适配器；报告审查只列线索，缺失的统计量要用原始数据计算

## 相关技能

- edu-analysis（计算缺失的统计量）、edu-review（完整的投稿前审稿）

## 状态

- Stable：作者已在真实研究材料上使用；复算在一篇已发表论文的数据上验证；统计报告审查为新增功能，在预埋问题的样例上测试
