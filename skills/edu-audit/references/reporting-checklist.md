# 统计报告清单

依据 APA 第 7 版的定量研究报告标准（JARS-Quant）和教育学期刊的常见做法整理，用于判断 check_reporting.py 列出的线索是否确实需要补充。具体格式以目标期刊的作者须知为准。

## 每类检验应报告什么

| 分析 | 正文或表格中应有 | 常见问题 |
|---|---|---|
| t 检验 | t(df)、p、效应量（Cohen's d 或 Hedges' g）及其区间；各组 M、SD、n | 只写 t 和 p；不报告是否方差齐性或用 Welch 校正 |
| 方差分析 | F(df1, df2)、p、η²、ηp² 或 ω²；事后比较方法和校正 | 事后比较不校正（LSD 不控制总体错误率） |
| 卡方检验 | χ²(df, N = …)、p、Cramér's V 或 φ；期望频数过小时用 Fisher 精确检验 | 缺自由度和效应量 |
| 相关 | r、p、n（或 df）；多个相关时用相关矩阵表 | 把相关写成"影响" |
| 回归 | B、SE、β、t、p 或 95% CI；R²、ΔR²；共线性诊断（VIF） | 只报告 β 和星号 |
| 调节效应 | 交互项系数及区间、简单斜率（在 ±1 SD 处）及区间，最好配简单斜率图 | 交互显著就直接解释方向 |
| 中介效应 | 间接效应及 bootstrap 置信区间（写明抽样次数和区间类型）、直接效应、总效应 | 用 Sobel 检验或只看 a、b 路径是否显著 |
| CFA / SEM | χ²(df)、CFI、TLI、RMSEA（及 90% CI）、SRMR；标准化载荷；CR、AVE；区分效度（HTMT 或 Fornell–Larcker）；估计方法（ML、MLR、WLSMV） | 只报告 χ²/df；不说明估计方法和缺失处理 |
| PLS-SEM | 外部载荷、CR、AVE、HTMT；路径系数、bootstrap 区间、R²、f²、Q² | 用 CB-SEM 的拟合指标评价 PLS 模型 |
| fsQCA | 校准锚点及依据、必要性分析（一致性、覆盖度）、真值表阈值（频数、一致性、PRI）、解的一致性和覆盖度、稳健性检验 | 不报告校准依据和 PRI |
| NCA | 上限线类型（CE-FDH、CR-FDH）、效应量 d、置换检验 p、瓶颈表 | 只报告 d 不报告显著性 |
| 多层模型 | ICC、设计效应、随机效应结构、估计方法、各层样本量 | 忽略班级嵌套直接做 OLS |

## 数字格式

- p 值写精确值（p = .032），小于 .001 时写 p < .001，不写 p = 0.000。
- 中文期刊多保留前导零（p = 0.032），APA 英文稿不能超过 1 的统计量（p、r、β）不写前导零；全文统一一种。
- 小数位一致：均值、标准差通常两位，p 值两到三位，相关和载荷两位（以期刊要求为准）。

## 全文层面

| 内容 | 位置 | 说明 |
|---|---|---|
| 样本量依据 | 研究设计 | 功效分析（G*Power 等）或经验规则；事后功效分析没有意义 |
| 缺失数据 | 研究设计 | 缺失比例、处理方式（删除、FIML、多重插补）及理由 |
| 共同方法偏差 | 研究设计或结果 | 问卷自评数据需要；Harman 单因子只是最低要求，可加单因子 CFA 比较或潜在方法因子（edu-analysis 的 edu_cmb） |
| 信度与效度 | 研究工具或结果 | α 只说明内部一致性，不证明效度 |
| 前提检验 | 结果 | 正态性、方差齐性、线性；不满足时说明采用的替代方法 |
| 软件 | 数据分析 | 软件和版本、主要的包 |
| 伦理 | 研究设计 | 伦理审批或知情同意；未成年人需监护人同意 |

## 审查表的写法

| 位置 | 问题 | 为什么重要 | 建议写法 |
|---|---|---|---|
| 结果第 2 段 | t 检验缺自由度和效应量 | 读者无法判断差异大小 | "实验组后测成绩高于对照组，t(96) = 2.31，p = .023，d = 0.47" ——df 和 d 需由原始数据计算，不能按已报告值估算后写入 |

建议写法中的数字只能来自稿件或实际分析结果；缺失的统计量交给 edu-analysis 计算。
