# `edu-research` 技能

[English](README_EN.md)

教育学科研的入口：判断任务、分派到合适的模块；负责选题、研究问题、理论框架、研究设计和样本量估计。

## 适合用它做什么

- 从一个主题出发提出可做的研究问题和设计
- 需要多步完成的项目（先分析数据，再写论文）
- 不确定该用哪个模块时

## 典型请求

- "围绕生成式 AI 与大学生自主学习，提出可做的研究问题和设计"
- "这个准实验要多少样本？"
- "根据这些数据写一篇论文"

## 你需要提供

- 主题或问题；已有的文献、数据或初稿（有就给）

## 产出

- 候选研究问题、理论框架、研究设计与分析方案、样本量估计；多步任务的分派和衔接

## 运行和依赖

- 无额外依赖；分析和写作的依赖见各模块

## 边界

- 不编造招募、伦理审批、数据或预注册

## 相关技能

- edu-analysis、edu-qual、edu-audit、edu-writing、edu-proposal、edu-review、edu-response

## 状态

- Stable：作者已在真实研究材料上使用；路由按场景盲测；四个使用场景在合成数据上试用
