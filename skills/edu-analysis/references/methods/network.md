# 方法卡：社会网络分析（SNA）

**适用**：在线讨论区的回帖网络（谁回复谁）、班级同伴提名（朋友、求助、合作）、教师合作与教研网络；回答"网络有多紧密""谁处在中心或桥梁位置""有没有小团体"。

**先检查**
- 数据整理成边列表 CSV：第 1 列发出者，第 2 列接收者，可选权重列（回复次数、互动频次）；另备节点表（第 1 列 ID，其余为属性，如性别、成绩），这样没有任何联系的孤立者也会计入。
- 有向还是无向：回复、提名是有向的（`directed = TRUE`）；共同参与、合作是无向的。
- 网络边界与缺失：提名式数据的应答率越低，密度和中心性的偏差越大（Kossinets, 2006）；未应答者的"被提名"仍可保留，但其出度为 0，需在结果中说明应答率。

**调用**
```r
source("edu_methods.R"); source("edu_methods_patterns.R")
e <- read.csv("inputs/edges.csv", fileEncoding = "UTF-8")      # from, to, n_reply
v <- read.csv("inputs/nodes.csv", fileEncoding = "UTF-8")      # id, gender, score
res <- edu_network(e, directed = TRUE, weight = "n_reply", nodes = v, community = "louvain")
edu_save(res, "network")
edu_network_plot(res, "output/network.png")   # 节点大小 = 入度，颜色 = 社群
```
输出：`network`（节点数、边数、密度、互惠性、传递性、平均距离、直径、成分数、入度/出度中心势、中介中心势、接近中心势、特征向量中心势、社群数、模块度 Q）；`nodes`（每个节点的入度、出度、强度、中介中心度及标准化值、接近中心度、特征向量中心度、所属社群，并附节点属性）；`communities`（社群规模）。

**判断标准**
- 密度、互惠性、传递性没有通用"好坏"界值，与同类研究或随机网络对比解释；平均距离小、传递性高表示"小世界"特征。
- 中心性（Freeman, 1979; Wasserman & Faust, 1994）：度数 = 直接联系多少，中介 = 处在他人之间的桥梁位置，接近 = 到达他人的步数少，特征向量 = 与中心人物相连。中心势越接近 1，网络越集中于少数人（如教师主导的讨论）。
- 社群：Louvain（Blondel et al., 2008）或 walktrap（Pons & Latapy, 2005），模块度 Q > .30 表示社群结构明显（Newman & Girvan, 2004）。
- 权重只用于强度、特征向量中心度和社群划分；距离类指标按步数计算（igraph 会把权重当距离，函数已关闭）。

**报告**
1. 网络整体特征表（节点、边、密度、互惠性、传递性、平均距离、中心势、模块度）。
2. 中心性排名前 10 的节点表（匿名编号），并附网络图。
3. 句子："讨论区回复网络包含 48 名学生和 312 条有向联系，密度为 .138，互惠性为 .42，平均距离为 2.31。入度中心势为 .37，说明回复集中在少数学生身上。Louvain 算法识别出 4 个社群（Q = .41）……"
4. 若比较节点属性与中心性（如成绩高者中心度是否更高），说明观测不独立，用置换检验（QAP）或 ERGM，而不是普通 t 检验或回归 p 值。

**常见错误**
- 把有向数据当无向处理，丢掉互惠与入度/出度差异。
- 遗漏孤立节点，导致密度被高估。
- 用普通显著性检验比较网络指标或节点中心性。
- 只放一张网络图、不报告任何量化指标；或只报告密度，不说明网络规模（密度随规模增大而下降，不同规模网络的密度不能直接比较）。
