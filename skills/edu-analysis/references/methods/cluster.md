# 方法卡：聚类分析（k-means、Ward 层次聚类、PAM）

**适用**：按若干连续指标把学生（教师、学校）分成几类，描述"学习者类型""投入模式""教师画像"等；常作为后续差异检验的分组依据。只有描述目的时用聚类；需要类别数检验、归属概率或协变量时用潜在剖面分析（LPA，见潜在类别方法卡）。

**先检查**
- 聚类变量 3–8 个、有理论依据，量纲不同时标准化（默认 `scale = TRUE`）；高度相关的变量会被重复加权，先看相关矩阵。
- 离群值会拉偏 k-means 的中心，PAM（中心点）更稳健；样本量至少为 2^变量数，最好达到 5 × 2^变量数（Formann, 1984 的经验规则，Dolnicar, 2002 推荐）。
- 缺失值：函数只用完整个案，删除比例在结果里写明。

**调用**
```r
source("edu_methods.R"); source("edu_methods_patterns.R")
d <- read.csv("inputs/data.csv", fileEncoding = "UTF-8")
res <- edu_cluster(d, c("behav", "cogn", "emot", "agentic"), k = 2:8,
                   method = c("kmeans", "ward", "pam"), scale = TRUE, seed = 123)
edu_save(res, "cluster")
# 看过各指标、结合理论确定 k 后重跑：edu_cluster(..., k_final = 4)
```
输出：`fit`（每种方法、每个 k 的组内平方和（肘部图）、平均轮廓系数、间隙统计量及 SE）；`selection`（轮廓系数最大的 k、Tibshirani 规则选出的 k、实际采用的 k）；`centroids_raw` / `centroids_z`（各类人数、百分比，原始单位与 z 分数的类中心）；`agreement`（方法两两之间的调整兰德指数 ARI）；`membership`（每个个案的类别，可并回原数据）。

**判断标准**
- k 的确定综合三类证据：肘部（组内平方和下降变缓处）、平均轮廓系数最大（> .50 结构合理，> .70 结构强，< .25 基本没有结构；Kaufman & Rousseeuw, 1990）、间隙统计量（Tibshirani et al., 2001），再加上可解释性和最小类人数（一般不少于样本的 5%）。
- 稳健性：不同方法同一 k 的 ARI（Hubert & Arabie, 1985）> .90 极好，> .80 良好，> .65 中等，≤ .65 说明分类不稳定（Steinley, 2004）。教育学论文常用"Ward 定 k、k-means 精修"的两步法（Hair et al., 2019）。
- 类别命名依据 z 分数中心（高于均值约 0.5 SD 称"高"，低于 -0.5 SD 称"低"），不是依据原始分。

**报告**
1. 表：k = 2–8 的轮廓系数、间隙统计量（可附肘部图），说明选 k 的理由。
2. 表：各类人数（百分比）与各指标的类中心（原始均值和 z 分数），并画剖面图。
3. 句子："采用 k-means 聚类（标准化变量，25 次随机起点），平均轮廓系数与间隙统计量均支持四类解（轮廓系数 = .46）。Ward 法与 k-means 分类的一致性较高（ARI = .82）。第一类'高投入型'占 31.2%，其行为、认知和情感投入均高于样本均值 0.6 SD 以上……"
4. 后续用类别做差异检验时，说明类别是数据驱动生成的，组间差异检验对聚类变量本身没有意义（必然显著），只对外部变量做比较。

**常见错误**
- 只看肘部图凭感觉定 k，或只报告一种指标。
- 用未标准化的变量聚类，量纲大的变量主导结果。
- 拿聚类变量本身做组间方差分析来"验证"分类。
- 把聚类类别说成"潜在类别"，或报告"分类正确率"——聚类没有这些统计含义，需要时改用 LPA（Nylund et al., 2007 的类别数确定流程）。
