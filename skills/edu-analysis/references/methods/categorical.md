# 方法卡：类别数据（卡方检验、Fisher 精确检验）

**适用**：两个类别变量是否相关，如性别与选课类型、年级与是否使用某工具、组别与通过/未通过。

**先检查**
- 每个人只计一次（同一人多次作答不能直接放进同一张列联表）。
- 期望频数：函数会报告期望频数小于 5 的格子比例。超过 20% 或有格子小于 1 时，自动追加 Fisher 精确检验（大于 2×2 时用蒙特卡罗法），以它为准。
- 类别过多、过稀时，先依据理论合并类别并说明理由，不按结果合并。

**调用**
```r
source("edu_methods.R")
d <- read.csv("inputs/data.csv", fileEncoding = "UTF-8")
edu_save(edu_chisq(d, x = "gender", y = "course_type"), "gender_course")
```
输出：列联表频数；检验表（Pearson χ²、df、p、Cramér's V 或 φ；2×2 另附 Yates 校正，必要时附 Fisher）；调整标准化残差（绝对值大于 1.96 的格子偏离独立性）。

**效应量**：Cramér's V（df* = 1 时 .10 小、.30 中、.50 大；类别更多时阈值相应降低）。

**报告**：χ²(df) = 值，p，V；再用调整残差指出差异主要来自哪些格子，例如"女生选择文科类课程的比例显著高于期望（调整残差 = 3.2）"。

**常见错误**
- 直接把百分比差异写成"显著"，不做检验。
- 期望频数过小时仍只报告卡方。
- 配对的类别数据（同一人前后两次的是/否）应该用 McNemar 检验，不用普通卡方：`mcnemar.test(table(d$pre, d$post))`。
