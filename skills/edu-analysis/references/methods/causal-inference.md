# 方法卡：准实验因果推断（倾向得分匹配、双重差分、断点回归）

**适用**：无法随机分组、又想估计干预或政策效果的研究。PSM：干预组和对照组在背景变量上有差异（如自愿参加项目的学生）。DID：有干预前和干预后的数据，并有一个未受干预的对照组（如试点学校与非试点学校）。RDD：是否接受干预由某个分数是否超过门槛决定（如入学分数线、奖学金线）。

**先检查（识别假设，用大白话说）**
- PSM：**可观测变量足以解释谁进了干预组**（条件独立）：影响分组、同时影响结果的因素都已测量并放进模型；两组倾向得分要有重叠（共同支持）。匹配变量只用干预前测得的变量，不放干预后才测的中介或结果。
- DID：**平行趋势**：没有干预时，两组的变化幅度本来相同；干预期间没有只影响某一组的其他事件。各单位接受干预的时间不同（交错实施）时，普通双向固定效应（TWFE）可能有偏（Goodman-Bacon, 2021），改用 Sun & Abraham (2021) 或 Callaway & Sant'Anna (2021)（R 包 did，本环境未装）。
- RDD：**门槛附近的人除了是否受干预外其他方面相近**：个体不能精确操纵自己的分数落到门槛哪一侧；门槛处没有同时发生的其他政策。运行变量（分数）要足够细，不能只有几档。

**调用**
```r
source("edu_methods.R"); source("edu_methods_causal.R")
d <- read.csv("inputs/data.csv", fileEncoding = "UTF-8")
edu_save(edu_psm(d, treat = "program", covariates = c("pretest", "ses", "gender", "grade"), outcome = "posttest"), "psm")  # 默认 1:1 最近邻、logit 倾向得分 0.2 SD 卡尺、ATT
edu_save(edu_did(d, outcome = "score", treat = "pilot", post = "after", cluster = "school"), "did")          # 2×2
edu_save(edu_did_event(panel, outcome = "score", unit = "school", time = "year", treat_time = "first_year"), "event")  # 从未受干预者 first_year 填 NA
edu_save(edu_rdd(d, outcome = "gpa", running = "entry_score", cutoff = 520, covariates = c("ses", "pretest")), "rdd")
```
输出：PSM 为匹配前后各协变量的标准化均值差（SMD）与方差比、匹配/未匹配样本量、匹配后加权回归的 ATT（按配对聚类稳健标准误、95% CI）及加入协变量的双重稳健估计；DID 为四格均值、DID 估计、聚类稳健 SE 与 CI；事件研究为各相对时期（前导、滞后）的系数与 CI、前导项联合检验，交错实施时另有 Sun & Abraham 估计和总体 ATT；RDD 为局部线性估计、稳健偏差校正 CI、带宽 h、两侧有效样本量、协变量在门槛处的跳跃、门槛两侧计数的二项检验。

**判断标准**
- PSM：匹配后所有协变量 |SMD| < 0.1（Austin, 2009），方差比在 0.5–2 之间（Rubin, 2001）；不达标就改倾向得分模型或匹配方法，不看结果变量反复调。卡尺丢掉的干预组个体要报告，此时估计只代表被匹配上的干预组。
- DID / 事件研究：干预前各期系数接近 0、CI 覆盖 0，才支持平行趋势；前导项检验不显著不等于趋势平行（检验力低，Roth, 2022）。聚类少于约 30 个时，聚类稳健 SE 不可靠，用 wild cluster bootstrap。
- RDD：报告稳健偏差校正 CI（Calonico, Cattaneo & Titiunik, 2014）；协变量在门槛处无显著跳跃；门槛两侧计数无明显差异。标准的密度检验是 rddensity（Cattaneo, Jansson & Ma, 2020），本环境未装，函数给出的二项计数检验是替代，需在文中说明。稳健性：带宽减半或加倍、二次多项式、安慰剂门槛、剔除紧贴门槛的个体（donut）。

**报告**
1. PSM：协变量平衡表（匹配前后 SMD、方差比）+ 样本量流向 + ATT。"采用 1:1 最近邻匹配（卡尺为倾向得分 logit 标准差的 0.2 倍），匹配后得到 152 对，各协变量 |SMD| 均小于 0.1。参与项目学生的后测成绩比匹配对照组高 3.12 分（95% CI [1.05, 5.19]）。"
2. DID：四格均值表 + DID 估计；有多期时附事件研究图（横轴相对时期，纵轴系数与 95% CI）。"与对照校相比，试点校实施后成绩多提高 2.75 分（SE = 1.36，95% CI [……]）；实施前各期系数均接近 0，未见明显的预先趋势差异。"
3. RDD：散点分箱图 + 主估计（含 h 与两侧有效 N）+ 协变量与密度检验 + 稳健性表。"在录取线附近，被录取使学业成绩提高 7.41 分（稳健 95% CI [4.09, 10.92]，h = 17.75，有效样本左 360、右 323）。"
4. 措辞：写"在……假设下，估计的效应为……"。PSM 结论加一句"匹配只能平衡已观测变量，未观测混杂可能仍然存在"；RDD 写"门槛附近的局部效应"，不外推到全体学生。

**常见错误**
- 匹配后不报告平衡，或只报告 p 值（平衡看 SMD，不看显著性检验）。
- 把 PSM 结果写成"证明了因果关系"；忽略未观测混杂（可加 Rosenbaum 界或 E 值敏感性分析）。
- 面板数据 DID 不按单位或干预分配层级聚类；交错实施仍只报告 TWFE。
- RDD 用全样本高次多项式拟合；只报告常规 CI；把局部效应写成总体效应。
