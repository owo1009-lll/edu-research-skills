# 方法卡：元分析（随机效应、调节变量、发表偏倚、三水平模型）

**适用**：合并多项已发表研究的效应量，回答"某干预/某关系总体上有多大、在哪些条件下更大"。常见于教育技术、教学干预效果、学业影响因素的综述论文。

**先检查**
- 文献检索与筛选按 **PRISMA 2020**（Page et al., 2021）报告：数据库与检索式、纳入排除标准、流程图（识别—筛选—纳入的篇数及排除理由）、双人独立编码及一致性（`edu_kappa`）。没有流程图的元分析一般会被退回。
- 效应量统一：组间均值差用 SMD（自动做 Hedges' g 小样本校正）；相关用 ZCOR（Fisher z，结果回转为 r）；二分类结果用 OR 或 RR（对数尺度合并）。已有 g 和方差时直接给 `yi`、`vi`。
- 同一研究贡献多个效应量（多个结果变量、多个年级）时不能当作独立样本，给 `study_id` 用三水平模型。
- 研究数少于 10 时，调节分析和发表偏倚检验的检验力都很低，只作描述。

**调用**
```r
source("edu_methods.R"); source("edu_methods_models.R")
d <- read.csv("inputs/meta.csv", fileEncoding = "UTF-8")
res <- edu_meta(d, "SMD", m1i = "m_t", sd1i = "sd_t", n1i = "n_t", m2i = "m_c", sd2i = "sd_c", n2i = "n_c",
                moderators = c("grade", "duration"), study_id = "study", label = "author_year")
edu_save(res, "meta")
edu_meta_plot(d, "SMD", m1i = "m_t", sd1i = "sd_t", n1i = "n_t", m2i = "m_c", sd2i = "sd_c", n2i = "n_c",
              label = "author_year", file = "output/meta")   # meta_forest.png, meta_funnel.png
```
相关类：`edu_meta(d, "ZCOR", ri = "r", ni = "n")`；研究少（k < 20）时加 `test = "knha"` 做 Knapp-Hartung 敏感性分析。

输出：各研究效应量与权重；合并效应（估计值、SE、95% CI、95% 预测区间，比值与相关已回转）；异质性（Q、df、p、τ² 及其 CI、τ、I² 及其 CI、H²）；元回归系数与 QM、残差 τ²、R²；类别调节变量的亚组估计与组间 Q；Egger 回归检验与剪补法（补入篇数、调整后估计）；逐一剔除表（含 Cook 距离与影响点标记）；三水平模型的合并效应、水平 2/3 方差及占比、去掉水平 3 的似然比检验。

**判断标准**
- 默认随机效应（REML 估计 τ²），因为教育研究的样本、情境、测量都不同（Borenstein et al., 2009）。只在研究几乎是重复实验时用固定效应。
- 异质性：Q 检验显著说明真实效应有差异；I² 约 25%、50%、75% 分别为低、中、高（Higgins et al., 2003），但 I² 是比例而非量，必须同时报告 τ 和预测区间（IntHout et al., 2016）。
- 发表偏倚：Egger 检验 p < .10 提示小研究效应（Egger et al., 1997）；剪补法（Duval & Tweedie, 2000）只作敏感性分析；k < 10 不做推断（Sterne et al., 2011）。
- 三水平模型：方差分解按 Cheung (2014)；LRT 显著说明研究间（水平 3）异质性不可忽略。

**报告**
1. PRISMA 流程图；纳入研究特征表（作者年份、样本、学段、设计、效应量）。
2. 森林图；合并结果句："随机效应模型显示，干预对学业成绩有中等程度的正向影响，g = 0.48，95% CI [0.31, 0.65]，p < .001；异质性较高，Q(23) = 96.4，p < .001，I² = 76.1%，τ = 0.34，95% 预测区间为 [−0.24, 1.20]，说明在部分情境中效应可能接近零甚至为负。"
3. 调节变量表（亚组 k、g、CI、组间 Q 与 p；元回归 B、SE、p、R²）。
4. 发表偏倚：漏斗图 + Egger 检验 + 剪补法结果；逐一剔除后结论是否改变。
5. 有多效应量时报告三水平模型及各水平方差占比。

**常见错误**
- 只报告 I²，不报告 τ 和预测区间；把 I² 高低当成效应大小。
- 同一研究的多个效应量当作独立样本合并（应使用三水平模型或先在研究内合并）。
- 把亚组之间"一个显著、一个不显著"当成调节作用，不看组间 Q。
- 用失效安全数（fail-safe N）代替偏倚检验；把剪补法调整后的估计写成"真实效应"。
- 混合 SMD 与相关未换算，或对独立组和前后测设计的 d 不区分方差公式。
