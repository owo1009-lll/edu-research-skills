# 方法卡：必要条件分析（NCA）

**适用**：判断某个条件是否是结果的必要条件（没有它就不会有高结果），以及达到某一结果水平至少需要多高的条件水平。常与回归/SEM（充分性、平均效应）和 fsQCA（组态）配合使用。

**先检查**
- 必要条件假设要有理论依据，方向一般是"高结果需要高条件"。
- 数据为连续或有序得分（量表均分、潜变量得分）。散点图中左上角明显空白，才可能存在必要条件。
- 极端离群点会影响上限线，必要时报告去除前后的结果。

**调用**
```r
source("edu_methods.R")
d <- read.csv("inputs/data.csv", fileEncoding = "UTF-8")
res <- edu_nca(d, x = c("support", "efficacy", "belonging"), y = "engagement",
               ceilings = c("ce_fdh", "cr_fdh"), test.rep = 10000, bottleneck_steps = 10)
edu_save(res, "nca")
```
散点图与 CE-FDH 上限线：`edu_nca_plot(d, "support", "engagement", "output/nca_support.png")`（在 run_r.py 的运行里也能直接出图）。

输出：每个条件在两种上限线（CE-FDH、CR-FDH）下的效应量 d、置换检验 p 值、上限线准确度、上限区面积和范围；瓶颈表（结果达到 0%、10%……100% 时各条件至少需要的水平，NN 表示不需要）。

**判断标准**（Dul, 2016; Dul et al., 2020）：d ≥ 0.10 且置换检验 p < .05 时，可以认为是必要条件；0–0.1 小，0.1–0.3 中，0.3–0.5 大，≥ 0.5 很大。离散或等级数据以 CE-FDH 为主，连续数据可同时报告 CR-FDH。

**报告**
1. 必要条件效应量表：条件、上限线、d、p、准确度。
2. 瓶颈表，并用一两句话解释，如"学习投入达到 60% 时，教师支持至少需要达到 32.1%，自我效能至少需要达到 18.6%"。
3. 与回归或 SEM 的结果对照：某条件可能"不是显著的预测变量，但是必要条件"，或反过来。

**常见错误**
- 只看效应量，不做置换检验。
- 把必要条件写成充分条件（"有了 X 就会有高 Y"）。
- 用相关系数或回归系数判断必要性。
