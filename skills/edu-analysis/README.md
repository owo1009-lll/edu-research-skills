# `edu-analysis` 技能

[English](README_EN.md)

在 R 中完成教育研究的统计分析，每次运行都留下脚本、数据指纹、R 环境和日志。

## 适合用它做什么

- 问卷数据：信效度、CFA、共同方法偏差、SEM、PLS-SEM
- 组态与必要条件：fsQCA、NCA
- 实验与调查：t 检验、方差分析、非参数检验、卡方、回归、调节与中介
- 嵌套或纵向数据：多层模型、增长模型、交叉滞后

## 典型请求

- "检验这份量表的信效度，做共同方法偏差检验和结构方程模型"
- "在 SEM 之外再做 fsQCA 和 NCA"
- "比较实验组和对照组的后测成绩，控制前测"

## 你需要提供

- 数据文件（CSV、Excel）和变量说明（题项归属、计分方向、分组）

## 产出

- 结果表（CSV 与 Markdown）、三线表、运行记录（`edu_output/analysis/`）

## 运行和依赖

- R 4.1 及以上；缺少的包用 `scripts/setup_packages.R` 安装到用户库；首次使用先跑 `tests/known_answers.R` 自检

## 边界

- 拟合指标和阈值是惯例，不证明模型正确；横断面数据不写成因果；不按修正指数反复改模型

## 相关技能

- edu-writing（把结果写成正文）、edu-audit（复核已报告的结果）

## 状态
