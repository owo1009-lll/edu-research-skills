# `edu-review` 技能

[English](README_EN.md)

在原稿对应位置高亮并添加原生批注，指出有依据的问题，保留正文及已有批注、修订。

## 适合用它做什么

- 论文投稿前自查会被挑什么毛病
- 申报书提交前从评审视角检查

## 典型请求

- "从审稿人角度看看这篇稿子哪里会被拒"
- "模拟两位外审专家审这份申报书"

## 你需要提供

- 稿件或申报书；目标期刊或基金（有就给）

## 产出

- `原稿名_审稿标注版.docx` 或 `.pdf`：黄色为论证/表达建议，红色为明确错误，蓝色为待核实；批注说明依据及处理建议。默认不改正文，不另附审稿报告。

## 运行和依赖

- Python 3.9 及以上；依赖见 `requirements.txt`。需要时调用 edu-writing 和 edu-audit 的检查脚本；实际 Word 打开/渲染还需 Word 或兼容阅读器。

## 边界

- AI 模拟审稿，不是专家评审；不预测录用概率；不臆测作者身份
- 当前自动锚定覆盖 Word 主文/表格普通文字及带文字层的 PDF。域、超链接和修订等保留，内部锚定、扫描 PDF、签名文件的限制见 [文件说明](references/annotations.md)。用户明确要求改稿时按授权执行。

## 相关技能

- edu-writing（按批注及用户取舍改稿）、edu-response（回复真实审稿意见）、edu-audit（统计报告审查）

## 状态

- Beta：原生标注用公开合成稿和篡改反例验证；旧报告流程的使用记录不等于新批注流程已获真人验证。
