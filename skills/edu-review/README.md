# `edu-review` 技能

[English](README_EN.md)

投稿前模拟同行评审：两三位独立审稿人给出编号的问题和解决标准，再综合成修改清单。

## 适合用它做什么

- 论文投稿前自查会被挑什么毛病
- 申报书提交前从评审视角检查

## 典型请求

- "从审稿人角度看看这篇稿子哪里会被拒"
- "模拟两位外审专家审这份申报书"

## 你需要提供

- 稿件或申报书；目标期刊或基金（有就给）

## 产出

- 各审稿人报告（主要和次要问题、位置、为什么重要、怎样算解决）、综合报告、按优先级排列的修改清单

## 运行和依赖

- Python 3.9 及以上；会调用 edu-writing 和 edu-audit 的检查脚本

## 边界

- AI 模拟审稿，不是专家评审；不预测录用概率；不臆测作者身份

## 相关技能

- edu-writing（按清单修改）、edu-response（回复真实审稿意见）、edu-audit（统计报告审查）

## 状态

- Stable：作者已在真实研究材料上使用；检查脚本在预埋问题的样例上测试；完整流程在一篇合成稿件上试用（审稿人在独立子任务中完成）
