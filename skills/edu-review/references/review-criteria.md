# 审稿维度

每位审稿人按自己负责的维度逐项看，不硬凑意见；负责的某个维度没有发现主要问题时，在报告的"总体评价"中写明（例如"研究伦理方面未发现主要问题"）。

## 审稿人分工

| 审稿人 | 负责的维度（论文） | 负责的维度（申报书） |
|---|---|---|
| R1 方法与数据 | 研究设计、数据分析、结果报告、研究伦理 | 研究内容与设计（方法、技术路线、进度）、可行性 |
| R2 领域与理论 | 问题与贡献、文献与理论、解释与讨论、结论与建议 | 选题价值、学术史梳理、创新之处 |
| R3 编辑视角（可选） | 期刊契合、结构与篇幅、写作与规范，以及摘要、标题与正文是否一致 | 研究基础与预期成果、匿名与格式、文字 |

每位审稿人也可以指出分工以外的严重问题，但以自己负责的维度为主。审稿要求（briefs/）写明：负责的维度、目标期刊或基金、报告语言、[报告格式](report-format.md)、可以读取的材料（稿件和 script_outputs/），以及"不要读取其他审稿人的报告"。

## 论文

| 维度 | 看什么 | 常见的阻断性问题 |
|---|---|---|
| 问题与贡献 | 研究问题是否明确、值得回答；贡献与最接近的已有研究的区别是否说清 | 贡献只靠"首次""填补空白"，说不出与已有研究的具体区别 |
| 文献与理论 | 文献是否覆盖关键研究、按问题组织；理论如何推出假设或分析框架 | 理论框架与假设之间没有推导关系；遗漏直接相关的核心研究 |
| 研究设计 | 设计能否回答问题；样本与抽样；变量测量（量表来源、信效度） | 设计无法支持主要结论（如横断面数据下的因果结论）；关键变量的测量没有依据 |
| 数据分析 | 方法与问题和数据是否匹配；前提检验；共同方法偏差；缺失处理；稳健性 | 方法用错（如嵌套数据用 OLS 忽略聚类）；中介只做逐步法；fsQCA 校准没有依据 |
| 结果报告 | 统计量是否完整（自由度、效应量、区间）；图表与正文是否一致 | 正文与表格数字矛盾；只报告显著的结果 |
| 解释与讨论 | 解释是否超出证据；是否与已有研究对话；是否讨论了反面结果和替代解释 | 结论超出数据（推广到总体、因果化）；讨论只是复述结果 |
| 结论与建议 | 建议是否由发现推出、对象明确；局限是否如实 | 建议与本文发现无关，是通用的政策套话 |
| 写作与规范 | 结构、篇幅、术语统一、引用规范（GB/T 7714 或 APA）、摘要是否反映主要发现 | 摘要中的结果在正文找不到 |
| 期刊契合与篇幅 | 主题和方法是否符合目标期刊的范围；篇幅、各部分比例是否与研究论文相称（引言、综述、讨论是否过短）| 综述和讨论只有几句，达不到研究论文的深度 |
| 研究伦理 | 知情同意、伦理审批、数据与 AI 使用声明 | 涉及未成年人却没有监护人同意的说明 |

**中文期刊（CSSCI）审稿的常见关注点**：选题的现实意义和理论价值、"问题提出"是否有力、研究设计是否规范、结论与对策是否有针对性、文字是否简练、参考文献是否规范和足够新。

**英文期刊（SSCI）审稿的常见关注点**：对国际文献的贡献（不只是"在中国情境中验证"）、理论框架、方法的严谨性和透明度（预注册、数据可得性）、效应量和实际意义、局限的充分讨论。

## 申报书

| 维度 | 看什么 |
|---|---|
| 选题价值 | 问题是否重要、具体；学术价值和应用价值是否写实 |
| 学术史梳理 | 是否按问题的推进脉络梳理，指出已有研究做到哪一步、还缺什么；中外文献是否兼顾、是否够新 |
| 研究内容与设计 | 研究对象、框架、重点难点、目标是否清楚且相互对应；方法能否完成目标；技术路线和进度是否可行 |
| 创新之处 | 每条创新是否对应学术史中指出的不足；"首次""填补空白"有没有依据 |
| 研究基础 | 前期研究与本课题的关系；预研或试点的性质是否如实 |
| 预期成果 | 形式、数量和去向是否与周期相称 |
| 匿名与格式 | 活页是否出现姓名、单位、成果名称等可识别信息；字数是否超限 |

不同基金的评审指标和权重以当年公告为准；这里只列评审时常看的方面，不代表官方打分标准。
