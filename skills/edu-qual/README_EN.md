# `edu-qual` Skill

[中文说明](README.md)

Analysis of interviews, observations and open-ended responses, with every code traceable to its source passage.

## What To Use It For

- Reflexive thematic analysis (AI-assisted)
- Codebook content analysis
- Grounded-theory three-level coding with saturation checks
- Inter-coder agreement (kappa)

## Typical Requests

- "Do grounded-theory coding and build a model of how this develops"
- "Run a thematic analysis of these 20 interviews"
- "Code the open-ended answers with this codebook and compute agreement"

## What You Need To Provide

- Interview or observation texts (CSV or text files); names and schools to de-identify

## Outputs

- Codebook, open and axial coding tables, categories, saturation check, narrative with quotations, revision history

## Runtime and Dependencies

- Python 3.9 or later; raw material stays in `edu_output/private/`

## Boundaries

- Does not invent independent coders, saturation or member checks; AI themes remain candidate interpretations

## Related Skills

- edu-writing (write the findings as paper sections)

## Status

- Beta: tried on synthetic interviews
