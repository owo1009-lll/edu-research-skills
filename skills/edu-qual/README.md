# `edu-qual` 技能

[English](README_EN.md)

分析访谈、观察记录和开放题，所有编码都能追溯到原文位置。

## 适合用它做什么

- 反思性主题分析（AI 辅助）
- 代码本内容分析
- 扎根理论三级编码与饱和检验
- 编码一致性（κ）

## 典型请求

- "用扎根理论做三级编码，建一个形成机理模型"
- "对这 20 份访谈做主题分析"
- "按这个代码本给开放题编码并算一致性"

## 你需要提供

- 访谈或观察文本（CSV 或文本文件）；需要去标识的姓名、学校等

## 产出

- 编码本、开放/主轴编码表、范畴、饱和检验、带引文的结果叙述、修订记录

## 运行和依赖

- Python 3.9 及以上；原始材料只放在 `edu_output/private/`

## 边界

- 不虚构独立编码者、饱和或成员核查；AI 得出的主题是候选解释

## 相关技能

- edu-writing（写成论文段落）

## 状态

- Stable：作者已在真实研究材料上使用；合成访谈材料上试用
