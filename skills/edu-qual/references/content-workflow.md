# Codebook qualitative content analysis

Choose inductive categories from full selected source/context, or theory-directed operational categories from actually read framework passages. Record the reason and selected materials. This is distinct from reflexive thematic analysis: interpret category content/boundaries and refine a codebook; do not rename category counts as themes, grounded theory or all qualitative methods.

The assistant reads raw materials and creates internal annotations; the script validates traceability and snapshots, never automatically understands/codes a transcript. Users provide ordinary interviews/observations/open responses plus question and source/use information, not JSON.

Run from the project folder: python <skill>/scripts/content_analysis.py --segments ASSISTANT_PREPARED_PRIVATE_SEGMENTS --annotation PRIVATE_INTERPRETATION --output-parent NEW_PRIVATE_VERSIONS; use --parent PREVIOUS_VERSION for a genuine revision. Source segments retain IDs, document, speaker role, exact text and source_locator. Keep raw and full coded records private. Check permitted use and identifiable details before publishing necessary excerpts.

Annotations record question, approach=inductive_codebook_content_analysis|directed_codebook_content_analysis, meaning/coding/context/counting units, codebook with unique IDs, operational definition/include/exclude, origin, example/counterexample, and directed framework_source. Every assignment links an exact excerpt, original segment, code, role=support|counterevidence|alternative|context, evidence_kind and interpretive reason. Speaker ambiguity/interviewer prompts remain context; observation notes remain observer evidence. Every eligible uncoded segment gets a review reason. Read all selected documents including prompts and adjacent turns; give case/reflexive memos, selected scope and each category's interpreted finding/boundary/counterevidence review. Unobserved framework categories are labelled not_observed_in_selected_material, not asserted findings.

Category construction can be revised after rereading: store new source/annotation bytes, immutable version hashes, parent and changed fields/change_reason. Retain negative cases and emergent directed-analysis categories rather than force a theoretical fit. Existing parent/source mutation is refused. Separate additional-source corpora into documented new source versions.

Actual execution is single_AI_assistant_pending_researcher_review. There is no independent human coder, kappa, member check or saturation claim. If a real later design supplies independent coders and appropriate method, evaluate agreement in a separately documented task; this adapter does not invent it. Frequencies describe this coded corpus only, not prevalence, importance, causal effects or organizational effectiveness.

Pass categories, short checked evidence, counterinterpretations and located boundaries to the existing analysis/writing bridge. State organizer aspirations as aspirations, not youth behavior or verified policy response. Save full codebook/source map/version history separately from readable methods/results.actual interpreted versions remain private. Method source: Hsieh&Shannon2005 doi10.1177/1049732305276687, publisher-hosted original pp1279–1283.
