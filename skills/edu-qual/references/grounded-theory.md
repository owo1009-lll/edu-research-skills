# 方法卡：扎根理论三级编码

**适用**：从访谈或文本中归纳一个过程、机理或影响因素模型（如"……的形成机理""……的影响因素模型"）。中文教育学期刊常用程序化扎根理论（Strauss & Corbin）的三级编码；以建构主义扎根理论（Charmaz）为取向时按其术语写，不混用。

**材料与抽样**
- 记录访谈对象的选取方式（目的抽样、理论抽样）、人数、访谈时长和转录方式。留出 2–3 份访谈不参与建模，用于理论饱和检验。
- 访谈全文和个人信息放在 `edu_output/private/`，导出的编码表只含必要的匿名摘录。

**三级编码**
1. **开放式编码**：逐句阅读，给原始语句贴初始概念（a1、a2……），再把意义相近的概念归为范畴（A1、A2……）。每个范畴写清定义。
2. **主轴编码**：找出范畴之间的关系，归纳为若干主范畴。可用"因果条件—现象—情境—中介条件—行动策略—结果"的典范模型，也可直接说明主范畴之间的关系结构。
3. **选择性编码**：提炼核心范畴，用一条"故事线"把主范畴串起来，画出理论模型图（用 edu-writing 的作图工具，箭头区分影响关系和过程顺序）。
4. **理论饱和检验**：用预留的访谈重复编码，没有出现新的概念和范畴，主范畴之间也没有新关系，才能写"通过理论饱和检验"。`grounded_coding.py --order A,B,C --holdout C` 会给出逐份新增的概念和范畴，并按是否预留访谈给出可以怎么写。访谈太少（约 5 份以下）无法预留时，报告逐份新增情况，写"未进行严格的理论饱和检验"，不要宣称饱和。

**编码表格式**（CSV，便于检查和计算一致性）

| 列 | 内容 |
|---|---|
| segment_id | 片段编号：先用 edu-qual 的 `theme_analysis.py prepare` 切分材料，取 `segments.json` 中的 `id` |
| quote | 原始语句（匿名后的原文精确摘录） |
| concept | 初始概念 a 编号与名称 |
| category | 范畴 A 编号与名称 |
| main_category | 主范畴 |
| coder | 编码者（研究者或 AI_assistant） |

用 `python <edu-qual>/scripts/grounded_coding.py --prepared <准备目录> --coding <编码表.csv> --actor AI_assistant` 校验并保存版本：它检查每条引文是否为原文精确摘录、每个概念和范畴是否只归入一个上级，并导出开放式编码表、主轴编码表和饱和表（CSV 与 Markdown）。

**编码一致性**：有两位编码者独立编码同一批片段时，用 edu-analysis 的 `edu_kappa(编码者1, 编码者2)` 计算 Cohen's κ（一般 ≥ .70 可接受，≥ .80 良好），并报告分歧如何讨论解决。只有一位研究者或由 AI 辅助编码时，如实写明，不写"两位研究者背对背编码"。

**AI 辅助的写法**：AI 可以提出初始概念和范畴建议，但范畴命名、主范畴关系和核心范畴需要研究者审定。方法部分写明"借助 AI 生成初始编码建议，由研究者逐条审核修改"，不把 AI 编码写成人工编码。

**报告**
- 方法部分：抽样、访谈、转录、编码程序、一致性检验（如有）、饱和检验。
- 结果部分：开放式编码表（节选，每个范畴给一两条原始语句示例）、主轴编码表（主范畴—对应范畴—内涵）、故事线与模型图，再逐个主范畴展开阐释，引用访谈原话（标注受访者编号）。

**常见错误**
- 编码表只有概念名称，没有原始语句，无法追溯。
- 没有做饱和检验就宣称"理论饱和"。
- 用编码频次判断范畴重要性。
- 把模型中的箭头写成已经验证的因果关系；扎根理论得出的是待检验的理论命题。
