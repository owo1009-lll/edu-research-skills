# 教育学论文写作

接受论文、结果、参考文献、笔记、初稿或一句普通的写作请求。证据记录由助理在内部整理，不要求用户准备 JSON。保留真实的研究问题、时间顺序、发现和有依据的作者意图。只有缺失的信息会实质改变研究判断时才询问。

## 步骤

1. **判断模式和语言。**
   - **新写**：根据材料组织论文。
   - **修改**：以用户原稿为底稿，即使要求"完成整篇"也一样。保留原稿的语言、研究问题、理论框架、有依据的核心主张、章节关系和作者语气，不另写一篇替代稿；先读 [修改原则](references/foundation.md)。用户明确要求重构、翻译或另起稿时照办。
   - **局部修改**：一句话或一段的修改直接完成，不启动完整流程。
   - **新写一节或一段**（如摘要、研究结果、某一部分讨论）：按第 3 步的路线写，做首稿、评阅、修订，跳过第 4、5 步。
   - **写几个部分、其余由作者写**（如"只写引言、综述和讨论"）：跳过主线确认，但仍建第 5 步的依据表和术语表。讨论中的数字以作者已有的结果为准，结果还没写出来时在依据表里列出要对齐的数值。章节编号为作者要写的部分留出位置（如一、二、五、六）；附上已写部分的参考文献表，说明作者补写后需要合并：顺序编码制（GB/T 7714）整篇重排编号，作者–年份制（APA）合并后按字母重排。中文期刊的"摘要和关键词"包括题目、英文题名、英文摘要和关键词。
   - **材料中的数字前后矛盾时**（同一统计量两个 p 值、自由度与人数不符），不自行选择，列入作者待办，正文避开有矛盾的数值。
   - **根据已发表研究写作**（示范或二次写作）：用户表示要投稿时，先直接告诉用户以他人研究投稿属于抄袭，产出只能用于练习或示范（见 [共同规则](../edu-shared/references/integrity.md) 第 6 条），并在文稿首页标明"二次写作示范，原研究为……"。正文的"本研究"指原研究，只引用原文引用过、能核实的文献。
   - **写作语言**跟随用户请求和目标期刊：投 CSSCI 写中文，投 SSCI 写英文；无法判断时问一句。
2. **读语气和写法规则。**中文读 [voice-zh](references/voice-zh.md) 和 [写法](references/prose-zh.md)，英文读 [voice-en](references/voice-en.md) 和 [prose-en](references/prose-en.md)。要点：
   - 发现直接陈述，动词与设计相符；不确定性放在原因解释上；局限集中写一次，并转成后续研究。
   - 论证在段内完成：论断在前、引注在句末，段末停在证据或具体推断上，价值句只在引言末句和结语出现。
   - 讨论用文字复述发现，与已有研究对照、用理论解释，不重复统计量，不提"还可以做的分析"。
   - 中文期刊要有核实过的国内文献和国内背景；投中文期刊的完整论文默认附英文题名、摘要和关键词。
   - 英文稿与中文稿的做法不同：
     - 引言和综述一半以上的句子带引注，"Author (year) found"式引用只占约十分之一；每处引注只用于该文献实际支持的论断，参考文献少时引用密度低于中位数是正常的，不为凑密度把文献挂到它没说过的论断上；
     - 综述先综合、再举一两项研究；
     - 讨论不用论断式小标题，启示写成段落而不是编号清单；
     - 句子中位约 25–27 词，超过 40 词的约占七分之一；不要为了缩短句子把文字切成碎句；
     - 定量、定性、混合研究的写法有差别（研究问题与假设、结果段开头、讨论中的引用方式、局限条数），见 prose-en 第 7 节。
3. **只读需要的路线：**

   | 要写什么 | 读这里 |
   |---|---|
   | 标题、摘要、关键词 | [摘要与标题](references/abstract-title.md) |
   | 引言、问题提出 | [引言](references/introduction.md) |
   | 文献综述、研究假设 | [文献综合](references/synthesis.md) |
   | 研究设计、研究方法 | [研究方法部分](references/methods-section.md) |
   | 根据 edu-analysis 或 edu-qual 的实际结果写结果 | [分析衔接](references/analysis-bridge.md)、[图表](references/figures-and-tables.md) |
   | 定量讨论 | [定量讨论](references/quantitative-discussion.md) |
   | 定性结果与讨论 | [定性叙述](references/qualitative-narrative.md) |
   | 结论、建议与启示、局限 | [结论与建议](references/conclusion-implications.md) |
   | 纯理论论证 | [理论论证](references/conceptual-argument.md) |

   引言、讨论、结论一起写时合并相应路线，不从结果倒推事前假设。各路线引用的 [写法卡](references/methods/) 是从已发表论文归纳的写法，修改原稿时只用来修复已识别的问题，不强加新提纲。
4. **完整论文：动笔前先确认一次主线。**新写或整篇修改时，先给用户一屏内容：研究问题、核心贡献（一两句）、章节提纲（每节做什么）和关键证据。用户确认或修改后，按 [完整论文流程](references/full-manuscript.md) 一次做完，不逐章确认。用户说"直接写"时跳过这一步。
5. **列写作依据表和术语表。**完整论文和大段改写在动笔前，在任务文件夹里建 `rationale.md`，一行对应一个写作单元：

   | 单元 | 功能 | 论点 | 证据或来源 | 写法或改动理由 |
   |---|---|---|---|---|

   修改原稿时，"改动理由"写明属于原文错误、实际结果要求，还是待确认材料。同时列一张术语表：每个构念、变量和方法只定一个名称（如"学习投入"不与"学业投入"混用）和一个缩写，首次出现时定义。这两张表是动笔前的计划，写完后用来逐行核对终稿。
6. **首稿、评阅、修订。**
   - 保存完整首稿后做一次聚焦评阅，抓最影响论证的 3–5 个问题：事实、结果和引用是否准确，问题与贡献，证据之间的关系，解释是否站得住，推进顺序，重要遗漏或重复。
   - 运行 `python <本skill>/scripts/check_voice.py --draft <首稿> --source <材料或结果文件>`：列出免责句、散落的局限句，以及材料中找不到的数字。
   - 运行 `python <本skill>/scripts/check_prose.py --draft <首稿>`（自动识别中英文），按部分对照已发表论文：
     - 中文稿对照 27 篇 CSSCI：句长、引用密度、点名作者式引用、讨论中的统计量和"审稿人口吻"、段末价值句、套话、双"的"名词链和自称；
     - 英文稿对照 50 篇 SSCI（定量、定性、混合研究分别有中位数）：引用密度、带引注的句子、点名作者式和成组引注、讨论与结果中的数字、句长和段长、we、被动语态、缩写、段首连接词、段末价值句、路线图句和 AI 常用词。

     英文稿的输出同时列出已发表论文的中位数；离中位数很远的数值即使没有触发提示，也要回到原文看一遍。
   - 完整论文或多节稿件再运行 `python <本skill>/scripts/check_consistency.py --draft <首稿> --term-group 名称=写法1|写法2`：查摘要数字是否在正文出现、样本量、同一数值的小数位、术语和自称、缩写定义、图表编号、引用编号（GB/T 7714 顺序编码）是否前后一致。
   - 脚本只列线索，逐条回到原文判断。修订一次（一轮完整的修订；之后按脚本提示做的小改不算新一轮）后交付。评阅只是 AI 自查，不称为专家审阅；用户要投稿前的外审模拟时用 edu-review，要回复真实审稿意见时用 edu-response。
7. **交付。**先给终稿和必要的简短说明。首稿、评阅、终稿、`rationale.md` 和来源位置存在 `edu_output/writing/<新任务文件夹>/`。
   - 完整论文的 Word、图表和引用核验见 [文件交付](references/file-delivery.md) 和 [引用核验](references/reference-verification.md)。
   - 不是整篇论文的交付（摘要、结果部分、研究发现、报告）用 `scripts/md_to_docx.py` 把 Markdown 转成 Word（中文三线表、宋体，`--superscript-citations` 处理 GB/T 7714 上标）。
   - 图用 `scripts/make_figures.py`，中文图在 spec 中加 `"language": "zh"`，模型图的每条边写 `relation`（`influence` 影响、`association` 关联、`sequence` 过程顺序、`hypothesized` 待检验、`candidate` 候选）。

规则的来源和验证范围见 [规则来源](references/source-basis.md)。诚信要求见 [共同规则](../edu-shared/references/integrity.md)。
