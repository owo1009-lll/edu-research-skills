# `edu-writing` 技能

[English](README_EN.md)

根据证据写作或修改中英文教育学论文，语气按已发表的 CSSCI 与 SSCI 论文校准，修改时保留作者的论证。

## 适合用它做什么

- 写某一部分：摘要、引言、综述、方法、结果、讨论、结论与建议
- 写完整论文并交付 Word（三线表、图、核验过的引用）
- 修改、润色原稿
- 全文一致性检查和写法检查（中文稿对照 27 篇 CSSCI、英文稿对照 31 篇 SSCI 论文的段落写法、引用方式、句长和套话）

## 典型请求

- "写一篇投《电化教育研究》的完整论文"
- "写英文 Discussion"
- "修改讨论部分，保留我的论点和结构"
- "检查全文前后数字和术语是否一致"

## 你需要提供

- 研究背景、方法、结果（或 edu-analysis 的输出）、参考文献；修改时给原稿

## 产出

- 正文或 Word 稿、图表、引用核查表、写作依据表、评阅记录

## 运行和依赖

- Python 3.9 及以上；Word 和图需要 python-docx、matplotlib（`requirements.txt`）；不需要 R

## 边界

- 不编造数据、文献和引文；AI 评阅是自查，不是专家审稿；中文文献在知网的核实由用户完成

## 相关技能

- edu-analysis、edu-qual（先做分析）、edu-review（投稿前外审模拟）、edu-response（返修）

## 状态

- Beta：语气在 42 篇已发表论文上校准，并做过同材料改前改后对照（Claude 和 Codex）；完整流程在合成数据上试用
