# 目标期刊与编辑团队相关研究

用户指定目标期刊、要求按该刊修改，或明确查编辑团队研究时使用。没有目标期刊就沿用普通文献检索，不为凑引用自行挑选编辑。记录由助理整理，用户无需填写JSON。

## 从稿件建立检索问题

从稿件、摘要或构想提取研究问题、核心概念、理论、对象、设计与方法、主要发现；尚无结果的方案明确记为未产生。保留作者框架，先明确待支持、待比较或需回应的论断，再找文献。关键词同时覆盖可能支持和挑战当前判断的证据。

## 核实身份并分开三个检索入口

先查期刊官网的刊名、出版社/出版组织、官网、ISSN、现任主编及副主编，以及与问题相关的领域编辑；特刊投稿另查对应征稿页的客座编辑和日期。记录页面位置与查询日期。旧论文署名、历任页面、编委顾问、出版行政及文字编辑不自动视为现任学术编辑。学校或期刊页面冲突时保留冲突及日期，继续核实。

用机构主页、ORCID或官方出版记录核实研究者身份。同名、首字母缩写或相同姓氏不足以认定作者；机构变更可以通过履历/出版清单连接，不能只因旧机构不同就排除。ORCID也可能被网页误填，冲突需交叉核对。编辑身份不表示此人会处理或评审稿件。

| 入口 | 查什么 | 用途 |
|---|---|---|
| A | 目标期刊中与问题、概念、对象或方法相关的研究 | 了解最接近的刊内论证与证据 |
| B | 相关编辑在**任何期刊**发表的研究 | 增加实质相关成果的检索入口；不只查本刊 |
| C | 必需的其他理论、方法、相反或竞争证据 | 防止按作者身份缩窄证据范围 |

可用宿主浏览工具完成检索，或用辅助脚本：

```text
python <edu-writing>/scripts/search_journal.py search --brief brief.json --limit 8 --out discovery.json
python <edu-writing>/scripts/search_journal.py check --record discovery.json --decisions decisions.json --out decision-check.json
```

`brief`含`manuscript`六项信息、`journal`身份与官方证据、`editors`角色及个人身份证据、`queries.A/C`。编辑条目含`id/name/role/status/role_evidence/identity/search_terms`；`identity`有`status/basis/evidence`及可选ORCID。`evidence`统一为`url/locator/checked_at`。可运行格式见 [公开端到端示例](https://github.com/owo1009-lll/edu-research-skills/tree/main/evals/capability-20261013/journal)。

脚本用Crossref的ISSN限定A，用作者姓名加主题查B且不限制刊名，用主题查C；结果只是候选，姓名查询可能带入同名者，ORCID收录也不完整。保存每条检索式、日期、错误和返回范围；接口失败不是“没有相关研究”。这是有界普通检索，不称系统综述。浏览补充找到的文献连同检索来源加入记录，不伪称API自动返回。

## 阅读、取舍和引用

沿用 [引用核验](reference-verification.md) 与`verify_references.py`，核实身份、更正、阅读范围及论断位置。每篇建议需有完整文献信息与DOI/稳定链接；如适用，编辑身份来源及**该篇作者**的身份依据；实际阅读范围；与稿件的具体关系；支持或需回应的论断；建议位置；纳入、备选或不纳入的理由。

建议的`purpose`分为`citation`、`writing_example`、`editorial_scope`。社论可帮助了解方向，但不是学生成效的实证证据；写法值得参考也不自动构成引用理由。只读摘要时，论断限于摘要实际报告的内容；来源片段写明具体范围。脚本只检查记录完整性与声明的标识冲突，不能验证相关性或保证官方身份和语义正确。

没有合适的编辑成果就不引用。不设置篇数或比例，不因编辑身份忽略相反证据，不声称引用可提高录用概率。用户要求修改稿件时，将核实后的成果写入实际论证，解释它如何影响问题、比较或判断；正文不介绍作者的编辑身份。无法读取的旧引文保留待查记录，不擅自清空原作者的理论框架。

如兼作蒸馏材料，另记具体写作观察及适用范围；引用用途和蒸馏用途分别判断。少量样本的共同写法不是该刊要求，编辑个人研究偏好不是录用标准。正式格式与投稿要求仍以查询当日作者须知为准。

`edu-ppt`路线A在用户指定目标期刊、需要定位贡献时可复用核实后的文献；路线B文章解读不默认启动编辑团队检索。
