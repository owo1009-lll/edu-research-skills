# Use discrepant results to compare explanations

状态：条件性项目方法，待独立试用与人工审阅，不是已验证写作标准。解决从一个显著结果直接宣布机制、忽略不一致结果的问题。

从需要解释的具体对比出发，说明每个解释能解释什么、哪些证据与它相符、还缺少哪个区分。无需罗列所有想象得到的解释，也不要求每段重复这一顺序。

适用于结果或案例留下实质对比的讨论。不适合无机制问题的纯描述任务。误用包括补造未测机制、以完成者访谈解释退出者、把不显著说成等效。证据不足应缩小解释。

**English constructed example: fictional vocational-course study; not a published finding.**

**Weak**

> Reminders improved learning by increasing motivation. This agrees with previous studies and proves that reminders should be used in vocational education.

**Better**

> The reminder group completed more tasks on time, but it did not outperform the comparison group on the independent transfer task. One possible explanation is that reminders made it easier to schedule work without changing how participants approached it; completers mostly described the reminders as help with planning. Several completers also reported following the prompt without reconsidering their solutions, which suggests that the reminders supported compliance more than transfer. For vocational programmes, the findings support reminders as a low-cost aid to timely participation.

改进发生在解释对象、证据角色与待检验区别上：发现直接陈述（准时完成更多，迁移任务无差异），不确定性放在解释上，随后落到实践含义上。可检验的下一步（如加入反思提示）写进局限与展望，不留在讨论段内，讨论段对解释作出取舍。完成任务不再被改写成学习效果，候选解释不再冒充因果发现。访谈只来自完成者这一局限写在局限部分，不在本段追加免责句。

## 补充阅读后的条件修订

W47（Science 2010，PDF 3–4）保留男生考试表现的意外负向结果，并说明它未在其他结局中重复；项目归纳：反向结果应改变解释范围，不能只在附注承认。W48（Science 2011，PDF 2–4）把教师活动的功能和即时低风险测验连起来；学生到场与教师差异仍是可能解释，跨研究效应须与相称结局比较。W07（PDF 2–5）比较人群、成本和结局相称的效应背景；W09（PDF 2–8）用分开的研究检验理论连接，各研究不同结局不能拼成同一个人的中介链。原作者的机制解释保持为作者解释；没有直接机制证据时，用支持的具体关系和未决区别推进讨论，而非列举无材料的替代解释。
