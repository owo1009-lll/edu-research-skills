# Explain the premise behind an educational judgment

Use when a theoretical or practical recommendation depends on a concept, aim or value that has not been made explicit. Define the distinction that changes the judgment. Trace how the supplied premise and evidence support the conclusion, then address an objection only if it would change that conclusion. Name the consequences for an educational choice rather than listing desirable values.

N05 (Conceptual framework; Findings; Discussion; Tables1–2) documents teachers allocating finite support toward lower-performing learners and whole-group lessons around the middle, alongside regret about advanced learners. The authors describe levelling classroom support; the project asks which conception of adequate support warrants such allocation. The normative priority is not established by interviews or by unmeasured student outcomes. C20 (instrument Table3; Results; Discussion) distinguishes generating a model from submitting generated work and disclosure from non-disclosure: participants' acceptability judgments clarify a dispute but are not universal ethical rules. Prior M05 conceptual sources remain historical sources, not new empirical readings.

A premise may be sufficient for this argument without being necessary for all routes to the conclusion. If a value remains disputed, present the conditional recommendation and the consequence that would inform the decision. Do not add an objection paragraph when the supplied argument is already clear and bounded.

Exception: empirical description may be the task, with no normative conclusion requested. Do not upgrade a reported concern into an optimal policy or verified harm.
