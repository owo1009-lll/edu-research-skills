# 研究方法部分

数字来自 27 篇 CSSCI 与 15 篇 SSCI 实证论文的结构统计（仓库 `distill/results/sections_summary.md`）。只写实际发生的设计和程序：抽样方式、回收率、伦理审批、知情同意、施测时间等材料中没有的，列入"作者待办"，不在正文中补写。

## 标题和顺序

- 中文一级标题多用"研究设计"（20/27），也有"研究方法"（3/27）。英文用 Method 或 Methods（13/15）。
- 研究问题或假设放在文献综述后的"研究假设"部分或方法开头，不单独成章（中文语料 0/27 单设）。

## 问卷调查

中文稿按下面三个小节写（问卷调查类 8/8 按"样本 → 测量 → 分析"排列）：

**（一）研究对象（或数据来源）**
- 抽样方式（方便、目的性、分层、整群）——语料中只有 14/27 写明，审稿常问；
- 施测时间和方式（线上、纸质），发放数、有效数和有效率，剔除标准；
- 样本构成（性别、年级、学科等），可以放在一张表或一段话里。

**（二）研究工具（或变量测量）**
- 每个量表一段：来源（原作者与年份，改编时说明改了什么、怎样翻译回译）、维度和题项数、计分方式、本样本的信度（7/8 逐个量表这样写）。
- 信效度放在方法部分（中文 14/19、英文 11/11）；CFA 的拟合和 CR、AVE、区分效度可以在这里报告，也可以在结果开头单设测量模型小节。
- 控制变量写明为什么控制、怎样编码。

**（三）数据分析**
- 软件和版本（两种语言都写；中文语料只有 13/27 写了版本）；
- 分析步骤：缺失处理、共同方法偏差的处理、主要模型、中介或调节的检验方法（如 bootstrap 次数和区间类型）。
- 共同方法偏差：方法部分写程序控制（匿名作答、反向题、分开施测）；统计检验在中文稿中通常作为结果部分的第一小节（语料中 4/4 如此），英文稿放在方法部分（2/2）。edu-analysis 的 `edu_cmb` 同时给出 Harman、单因子 CFA 比较和潜在方法因子。

篇幅：问卷调查稿的方法部分约占正文的八分之一到五分之一（中文中位 13%）。

## 实验与准实验

- 小节：被试与分组（分配方式、各组人数）→ 干预或任务设计（各组做了什么、持续多久、由谁实施）→ 测量工具 → 实验程序（时间线）→ 数据分析。
- 篇幅主要用在干预和程序上，约占正文四分之一以上（中文中位 27%、英文 30%）。
- 样本量依据：有功效分析时写出效应量假设和检验力（语料中很少写，1/27、1/15，但实验研究审稿常问）；没有时不补写。

## 质性研究

- 小节：研究对象与抽样（目的性抽样的标准、人数、编号方式）→ 资料收集（访谈提纲的主要问题、时长、录音转录）→ 资料分析（编码步骤，扎根理论写出开放、主轴、选择性编码各做了什么）。
- 可信度措施如实写：饱和检验、双人编码与一致性、协商、参与者核验、三角互证——只写实际做过的（edu-qual 的记录中有哪些写哪些）。
- 英文稿常写研究者立场（researcher positionality）。

## 伦理与报告

- **英文稿**：写伦理审批（机构和编号）和知情同意（语料 10/15 写审批，8/15 写知情同意）。
- **中文稿**：至少写一句知情同意和匿名处理（语料中约一半有伦理表述）；涉及未成年人写明监护人同意。
- 材料中没有这些信息时，不写进正文，列入作者待办。
- 数据收集的具体年月、软件版本这类细节审稿人容易核对，有就写。

## 写完后检查

- 研究对象部分的样本量与摘要、结果、表格一致（`check_consistency.py`）。
- 方法部分提到的每个分析，结果部分都有对应的报告；结果中出现的分析，方法部分都有说明。
- 统计报告是否完整，可以用 edu-audit 的 `check_reporting.py` 检查。
